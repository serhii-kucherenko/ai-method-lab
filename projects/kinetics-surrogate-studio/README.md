# Kinetics Surrogate Studio

Method-lab soft-sim for entropy-constrained chemical kinetics surrogates vs full-rate baselines.

Inspired by [arXiv 2607.09582](https://arxiv.org/abs/2607.09582v1). Soft-sim only — not certified CFD, not live plant, not the authors’ system (no published code).

## Run

```bash
npm install
npm run dev
```

Bearer token for API: `ks-dev-token`.

## Tests

```bash
npm test
npm run build
npm run test:app-up
```

Offline demo: open `try.html`.
