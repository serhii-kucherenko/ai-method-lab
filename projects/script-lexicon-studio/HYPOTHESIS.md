# Hypothesis — Script Lexicon Studio

If NLP leads can see expanded Ge'ez-script lexicon scores beat baseline multilingual tokenizers on the same soft-sim inputs, they will treat lexicon expansion as a pack-lock decision — not a one-off tokenizer tweak.

Paper pattern (VEXMLM / arXiv 2607.15209): adding Ge'ez-script subwords improves Amharic and Tigrinya coverage vs plain multilingual baselines. This product tests that buyer story in a method-lab studio, not a rebrand of the authors' system.
