# Surveil Gate Studio

Soft-sim studio for **six-pillar trust governance** of generative AI in digital public health surveillance — compared against an **explainability-only baseline** before locking a surveillance pack.

## Quick start

```bash
npm install
npm test
npm run build
npm run test:app-up
npm run dev
```

Offline demo: open `try.html`.
