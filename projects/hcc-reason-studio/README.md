# HCC Reason Studio

Soft-sim studio for comparing clinical-reasoning LLM HCC risk stratification against non-reasoning baselines.

## Run

```bash
npm install
npm run dev
```

Bearer token for API: `hcc-dev-token`.

## Tests

```bash
npm test
npm run build
npm run test:app-up
```

## Honesty

Soft-sim only; not CDS; not live EHR; not authors’ system. Paper: https://arxiv.org/abs/2607.08602v1
