# Margin Fusion Studio

Soft-sim studio for surgical imaging leads: case packs, specimen scans, deformable fusion configs, and dual A/B (marker-free vs marker-based) before locking a pack.

**Paper:** [arXiv 2607.13343](https://arxiv.org/abs/2607.13343v1) · authors’ code: none  
**Honesty:** soft-sim only; not surgical device cleared; not live OR; not the authors’ system.

## Run

```bash
npm install
npm run dev
```

Dev bearer token: `margin-fusion-dev-token`

## Tests

```bash
npm test
npm run build
npm run test:app-up
```
