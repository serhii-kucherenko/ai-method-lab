# Cache Hit Studio

Soft-sim studio for computational chemistry / immuno-oncology discovery leads who compare **structured CACHE-style computational hit-finding** against a **naive docking baseline** before locking a hit pack.

## Run

```bash
cd projects/cache-hit-studio
npm install
npm run dev
```

Open http://localhost:3000

## Tests

```bash
npm test
npm run build
npm run test:app-up
```

## Honesty

Soft-sim only — not wet-lab validated hits, not live ELN write-back, not FDA cleared, not CACHE, not the authors’ system.

Paper: https://doi.org/10.26434/chemrxiv.15005792/v2 · authors’ code: none published

Offline demo: open `try.html` in a browser.
