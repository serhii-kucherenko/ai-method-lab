# Oncology Report Studio

Soft-sim bench for multi-LLM collaborative MRI report drafts vs single-LLM baselines.

**Paper:** https://arxiv.org/abs/2607.14581v1 (authors’ code: none)

## Run

```bash
npm install
npm run dev
```

Bearer token for API: `ors-dev-token`

## Test

```bash
npm test
npm run build
npm run test:app-up
```

## Offline

Open `try.html` for a no-server dual-score demo.
