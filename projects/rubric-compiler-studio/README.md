# Rubric Compiler Studio

**Lock the rubric. Score with evidence.**

Rubric Compiler Studio is a Method Lab soft-simulation for platform, QA, and learning teams. It turns locked criteria into evidence-anchored scores, fits calibration against human references, and routes low-trust cases to review.

## Run
```bash
cd projects/rubric-compiler-studio
npm install
npm run dev
```

## Verify
```bash
npm test
npm run build
npm run test:app-up
```

## Dual scorer
- **A — compiled:** locked criteria, evidence anchors, calibration fit, and selective escalation.
- **B — holistic:** a fluent score with no evidence trail and no escalation.

## Honesty
Method Lab soft-simulation only; not certified psychometrics or a live judge write-back. It is not a RULERS, Autorubric, or PReMISE product. Open `try.html` offline for the lightweight demo.
