# PRODUCT — Feature Sufficiency Studio

## Buyer outcome

Clinical ML ops leads know whether a partial-observation mask is still sufficient versus a full-feature baseline before locking an eval pack.

## Surfaces

- Feature pack registry (`/features`)
- Observation mask editor (`/masks`)
- Cohort case workspace (`/cohorts`)
- Sufficiency runs (`/sufficiency`)
- Partial vs full compare + delta scoreboard
- Pricing, demo, onboarding, multi-flow index, honesty fence, settings

## Platform must-haves

Bearer auth, org/members, webhook HMAC, audit, export, search, pagination, rate limit, ≥30 dual goldens, `try.html`.
