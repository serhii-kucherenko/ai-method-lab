# Enhanced Flu Studio

Soft-sim studio for public-health / vaccine-program analytics leads who need to compare **expanded enhanced influenza vaccine (EIV) programs** for adults ≥65 against **current national policy baselines** before locking a program pack.

## Run

```bash
cd projects/enhanced-flu-studio
npm install
npm run dev
```

Open http://localhost:3000

## Tests

```bash
npm test
npm run test:app-up
```

## Honesty

Not live immunization logistics. Not clinical prescribing. Not national policy adoption. Not the authors' Nordic EIV model.

Paper: https://doi.org/10.1016/j.vaccine.2026.128934
