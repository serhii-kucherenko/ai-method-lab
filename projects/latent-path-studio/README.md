# Latent Path Studio

Soft-sim studio for **multi-dimensional latent adolescent symptom trajectories** vs **single-domain baselines**.

## Quick start

```bash
npm install
npm run gen:goldens
npm test
npm run build
npm run test:app-up
npm run dev
```

Dev bearer token: `latent-path-dev-token`
