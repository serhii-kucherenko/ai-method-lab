# Omic Prior Studio

Soft-sim studio for precision-medicine / multi-omics analytics leads who compare **statistical-priors-informed transformers** against a **priors-free omics baseline** before locking an omic pack.

## Run

```bash
cd projects/omic-prior-studio
npm install
npm run dev
```

Open http://localhost:3000

## Tests

```bash
npm test
npm run build
npm run test:app-up
```

## Honesty

Soft-sim only — not clinical diagnostic use, not live EHR write-back, not FDA cleared, not OmicFormer, not the authors’ system.

Paper: https://www.medrxiv.org/content/10.64898/2026.07.06.26357359v1 · authors’ code: none published
