# Abe Precision Studio

Method-lab soft-sim for comparing domain-insertion adenine base editor precision vs baseline ABE windows.

## Quick start

```bash
npm install
npm run gen:goldens
npm run build
npm test
npm run test:app-up
npm run dev
```

Offline demo: open `try.html`.

## Stack
Next.js App Router · Tailwind · shadcn · TypeScript in-memory store.
