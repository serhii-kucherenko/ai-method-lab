# Findings — Persona Triage Studio

Built as a soft-sim Method Lab product inspired by arXiv 2607.08625 patterns (communication style altering triage outcomes). No authors’ code was published; scoring is an original dual-lane soft-sim, not a reimplementation of a named clinical system.

**What shipped:** persona packs, conversation cases with gold urgency, style axes, urgency runs, style-aware vs idealized-patient compare, disparity scoreboard, org/auth/webhook/export/audit platform surfaces, ≥30 dual-impl goldens, offline `try.html`.

**Honesty:** Not clinical advice; not FDA; soft-sim only.
