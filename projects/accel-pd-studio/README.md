# Accel PD Studio

Soft-sim studio for digital biomarker / neurology analytics leads who compare **multi-channel transformer physical-activity representations** from wearables against a **handcrafted PA-feature baseline** before locking an accel pack.

## Run

```bash
cd projects/accel-pd-studio
npm install
npm run dev
```

Open http://localhost:3000

## Tests

```bash
npm test
npm run build
npm run test:app-up
```

## Honesty

Soft-sim only — not clinical diagnostic use, not live device write-back, not FDA cleared, not PABformer, not the authors’ system.

Paper: https://www.medrxiv.org/content/10.1101/2025.08.12.25333460v2 · authors’ code: none published
