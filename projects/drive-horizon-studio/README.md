# Drive Horizon Studio

Industrial AV simulation / world-model eval studio — hierarchical coarse+detail vs flat naive rollout (soft-sim).

## Run

```bash
cd projects/drive-horizon-studio
npm install
npm run dev
```

Open http://localhost:3000

## Tests

```bash
npm test
npm run test:app-up
```

## Honesty

Soft-sim method-lab product. Not Orbis. Not live vehicle deployment. Not certification.

Paper: https://arxiv.org/abs/2607.15898v1 · Authors' code: none
