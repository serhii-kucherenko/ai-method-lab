# Pv Causal Studio

Soft-sim studio where pharmacovigilance / RWE analytics eng leads compare **target-trial causal signal detection** against a **spontaneous-reporting baseline** before locking a pv pack.

Paper: https://www.medrxiv.org/content/10.64898/2026.07.01.26356874v1 · authors’ code: none published

## Run

```bash
cd projects/pv-causal-studio
npm install
npm run dev
```

## Verify

```bash
npm test
npm run build
npm run test:app-up
```

## Honesty

Soft-sim only — not regulatory submission, not live claims write-back, not FDA cleared, not the authors’ system.
