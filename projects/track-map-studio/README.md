# Track Map Studio

Soft-sim studio for surgical robotics / intraoperative vision leads to compare **online deformable SLAM** against an **offline kinematics-prior baseline** before locking a track pack.

## Run

```bash
cd projects/track-map-studio
npm install
npm run dev
```

## Tests

```bash
npm test
npm run build
npm run test:app-up
```
