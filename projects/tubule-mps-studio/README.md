# Tubule Mps Studio

Soft-sim studio for transplant nephrology / MPS analytics leads comparing **voclosporin MPS** mitochondrial preservation against **cyclosporine A** baselines on recorded proximal-tubule packs.

## Run

```bash
cd projects/tubule-mps-studio
npm install
npm run dev
```

Open http://localhost:3000

## Scripts

- `npm run build` — production build
- `npm run test` — goldens + store + UI critical
- `npm run test:app-up` — live build + `next start` smoke
- `npm run gen:goldens` — regenerate `tm-001`…`tm-030`
