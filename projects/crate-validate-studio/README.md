# Crate Validate Studio

Soft-sim studio for ARC RO-Crate structural+semantic validation vs metadata-only baselines.

## Run

```bash
cd projects/crate-validate-studio
npm install
npm run dev
```

Open http://localhost:3000. Bearer token (dev): `crate-validate-dev-token`.

## Test

```bash
npm test
npm run build
npm run test:app-up
```
