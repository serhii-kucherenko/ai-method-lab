# PRODUCT — Drag Wall Studio

## Buyer outcome

Fluid-control leads manage channel packs, wall-actuation plans, and sensor layouts, then understand whether an ES closed-loop wall controller beats an open-loop/gradient baseline before a soft-sim handoff.

## Surfaces

- Channel pack registry (`/channels`)
- Wall actuator editor (`/actuators`)
- Sensor layout workspace (`/sensors`)
- ES closed-loop controller runs (`/controllers`)
- ES vs open-loop compare + scoreboard
- Pricing, demo, onboarding, multi-flow index, honesty fence, settings

## Platform must-haves

Bearer auth, org/members, webhook HMAC, audit, export, search, pagination, rate limit, ≥30 dual goldens, `try.html`.
