# Skeleton Author Studio

Soft-sim studio for accessibility / data-viz leads: version experience packs, author navigation skeletons and label templates, then compare **scaffolded visual authoring** against a **naive linear baseline** before locking a pack.

Paper: [arXiv 2607.14579](https://arxiv.org/abs/2607.14579v1) · Authors’ code: none

## Honesty

Soft-sim only. Not WCAG certified. Not live screen-reader OEM. Not the authors’ system.

## Run

```bash
npm install
npm run dev
npm test
npm run build
npm run test:app-up
```

Bearer token (dev): `skeleton-dev-token`

Offline demo: open `try.html`
