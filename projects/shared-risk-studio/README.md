# Shared Risk Studio

Soft-sim studio for shared multi-disease health representations versus disease-specific baselines.

## Run

```bash
npm install
npm run dev
```

## Test

```bash
npm test
npm run build
npm run test:app-up
```

## Honesty

Soft-sim only; not CDS cleared; not live EHR; not authors’ system / not RisQ brand.
