# Access Equity Studio

Soft-sim studio for **equity-access autism screening pathways** vs **accuracy-only classification baselines**.

## Quick start

```bash
npm install
npm run gen:goldens
npm test
npm run build
npm run test:app-up
npm run dev
```

Dev bearer token: `access-equity-dev-token`
