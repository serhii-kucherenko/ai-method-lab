# Reaction Loop Studio

Soft-sim studio for process chemists comparing **chemist-in-the-loop VLM** reaction-condition agents to **open-loop VLM** baselines before locking a campaign pack.

## Quick start

```bash
npm install
npm run dev
```

Bearer token (dev): `reaction-loop-dev-token`

## Scripts

- `npm test` — goldens, store, UI critical path
- `npm run build` — production build
- `npm run test:app-up` — live build + start smoke
- `npm run gen:goldens` — regenerate dual goldens

## Honesty

Soft-sim only. Not live wet-lab control. Not manufacturing cleared. Not the authors’ system.
