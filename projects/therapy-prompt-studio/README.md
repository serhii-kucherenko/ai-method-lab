# Therapy Prompt Studio

Soft-sim studio for comparing **structured therapy-safety gates** to a **prompt-only safety baseline** before locking a prompt pack.

## Run

```bash
cd projects/therapy-prompt-studio
npm install
npm run dev
```

Open http://localhost:3000 — primary CTA → `/prompts`.

## Tests

```bash
npm test
npm run build
npm run test:app-up
```

## Honesty

Soft-sim only — not clinical therapy, not a crisis hotline, not live patient chat write-back, not FDA cleared, not the authors’ system.

Paper: https://www.medrxiv.org/content/10.64898/2026.07.16.26358261v1 · authors’ code: none published
