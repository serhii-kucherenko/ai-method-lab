# Liver Organoid Studio

Soft-sim studio for organoid-platform / MASLD screening analytics leads: version model packs, configure lineages and assays, then compare **multicellular HLO** models against **single-lineage HLC** baselines before locking a pack.

## Run

```bash
cd projects/liver-organoid-studio
npm install
npm run dev
```

Open http://localhost:3000 — primary workspace is `/packs`.

## Tests

```bash
npm test
npm run test:app-up
```

## Offline demo

Open `try.html` for an approximate A/B soft-sim (no server). Full fidelity needs the Next app.

## Honesty

Method-lab soft-sim only. Not wet-lab validated organoid GMP manufacture, not live patient transplant, not clinical MASLD diagnosis, not the authors’ organoid system.
