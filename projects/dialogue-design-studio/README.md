# Dialogue Design Studio

Soft-sim studio for **productive open-minded dialogue feed designs** vs **engagement-maximizing baselines**.

Paper: [SocArXiv dngcj](https://osf.io/preprints/socarxiv/dngcj_v3/) · authors’ code: none

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Bearer token: `dialogue-design-dev-token`.

## Scripts

- `npm test` — goldens + store + UI critical
- `npm run build` — production build
- `npm run test:app-up` — live next start smoke
- `npm run gen:goldens` — regenerate `dd-001`…`dd-030`
