# Selective Trust Studio

**Escalate when unsure.**

Method Lab soft-simulation for platform and evaluation teams. Configure cheap-to-strong judge cascades, escalate uncertain scores, and compare selective trust against always-strong spend.

## Run
```bash
cd projects/selective-trust-studio
npm install
npm run dev
```

## Verify
```bash
npm test
npm run build
npm run test:app-up
```

## Dual scorer
- **A — selective:** cascade with confidence gates and escalate-when-unsure
- **B — always-strong:** never escalate; higher cost

## Honesty
Method Lab soft-simulation only. Not a production SLA guarantee. Not the Trust-or-Escalate paper brand.
