# Immunize Impact Studio

Soft-sim studio for **immunization-program analytics leads** comparing **immunization-linked under-five mortality panels** against **coverage-only dashboards**.

## Run

```bash
cd projects/immunize-impact-studio
npm install
npm run dev
```

Open http://localhost:3000

## Tests

```bash
npm test
npm run test:app-up
```

## Offline demo

Open `try.html` in a browser (approximate soft-sim; full fidelity needs the Next app).

## Honesty

Not live immunization logistics, not clinical prescribing, not national policy authority.
