# World Cog Drive Studio

Soft-sim studio for autonomy leads who compare dual-level world-cognitive VLA driving against single-level VLA baselines before locking a route pack.

## Run

```bash
npm install
npm run dev
```

Bearer token (dev): `world-cog-dev-token`

## Scripts

- `npm test` — goldens, store, UI critical
- `npm run build` — production build
- `npm run test:app-up` — live build + start smoke
- `npm run gen:goldens` — regenerate ≥30 dual goldens

## Honesty

Soft-sim only. Not certified AV. Not live vehicle control. Not the authors’ system. Paper: https://arxiv.org/abs/2607.08375v1
