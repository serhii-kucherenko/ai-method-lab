# Sovereign Cost Studio

Soft-sim studio for public-sector AI / sustainability leads who compare **sovereign AI infrastructure water–energy–emissions accounting** against a **naive cloud-footprint baseline** before locking a cost pack.

Paper: https://arxiv.org/abs/2607.13443v1 · Authors’ code: none published

## Run

```bash
cd projects/sovereign-cost-studio
npm install
npm run dev
```

Open http://localhost:3000

## Tests

```bash
npm test
npm run build
npm run test:app-up
```

Offline demo: open `try.html` in a browser.

## Honesty

Soft-sim only — not certified carbon audits, not live grid metering, not national policy authority, not the authors’ system.
