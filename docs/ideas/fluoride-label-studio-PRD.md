# PRD — Fluoride Label Studio

## Goal
Soft-sim studio where radiopharma chemistry leads compare fast isotopic fluorine-18 exchange labeling to multistep prosthetic-group baselines.

## Must-have (≥25)
Label pack CRUD, precursors, exchanges, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validated radiopharmaceutical GMP claims, live cyclotron control, clinical PET dosing, paper brand.
