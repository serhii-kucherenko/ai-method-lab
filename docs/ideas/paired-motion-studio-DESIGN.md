# Design — Paired Motion Studio

## Brand
**Paired Motion Studio** — soft-sim for distributed ego+exo HMD motion capture. Never claim live HMD fleet control, production mocap suit replacement, or Meta/Aria deployment. Never brand as EgoExoMoCap.

## Landing brief
- **Headline:** Capture whole-body motion when one view is not enough.
- **Support:** Capture packs for paired HMD sessions — compare distributed ego+exo fusion against ego-only baselines before you lock a pack.
- **Primary CTA:** Open sessions → `/sessions`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not live HMD fleet control; not production mocap replacement; not Meta/Aria deployment; not authors’ system
- Sources: arXiv 2607.15868 · authors’ code: none published

## Visual direction
- **Palette:** headset ink + motion teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--pm-ink: #14181f`, `--pm-teal: #2c6b73`, `--pm-mist: #eef3f5`, `--pm-line: #c2c8cd`, `--pm-amber: #c08a3a`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft dual-view motion mist
