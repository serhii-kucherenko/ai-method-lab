# Webhook Retry Debt Studio — Vision

Outbound webhooks quietly pile into retry limbo until an incident review becomes archaeology. Webhook Retry Debt Studio soft-sims a **failed and aging delivery debt queue** with destination owners and blast radius versus an ignore-backlog baseline so platform leads open the review with a cleanup pack, not a broker console dump.

**Refuse to become:** SQS/Kafka UI clone, org-settings “test webhook” ping, Stale Flag (feature flags), Schema Drift (migrations), or desk jobs/lifecycle shell.
