# PRD — Care Query Studio

## Goal
Soft-sim studio where clinical LLM eval leads compare multilingual POC medical query LLMs to local clinician baselines.

## Must-have (≥25)
Query pack CRUD, locales, answers, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Clinical diagnostic claims, live EHR write-back, FDA clearance, NigBench brand.
