# Vision — Transducin Measure Studio

## Problem
OCT quantitative measures sit in proprietary formats and private tags. Teams lack a soft-sim bench that compares SNOMED-CT coded recovery to raw private-tag dumps before locking a measure pack.

## Buyer
Ophthalmology imaging / clinical-data engineering leads.

## Promise
Version measure packs, configure parsers and DICOM SR exports, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not a crate or assay desk. Domain nouns: measures, parsers, exports, runs, compares.
