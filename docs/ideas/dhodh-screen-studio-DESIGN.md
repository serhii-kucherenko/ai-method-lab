# Design — Dhodh Screen Studio

## Brand
**Dhodh Screen Studio** — soft-sim for structure-based PfDHODH virtual screening vs naive library baselines. Never claim wet-lab validation, clinical antimalarial advice, IND/NDA readiness, or live compound procurement.

## Landing brief
- **Headline:** Dock the parasite enzyme. Compare the screen.
- **Support:** Screen packs for PfDHODH hit finding — compare structure-based virtual screening against naive library baselines before you lock a pack.
- **Primary CTA:** Open packs → `/packs`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not wet-lab validated; not clinical antimalarial advice; not IND/NDA ready; not compound procurement; not authors’ brand
- Sources: ChemRxiv 10.26434/chemrxiv.15005938/v1 · authors’ code: none published

## Visual direction
- **Palette:** parasite ink + screen teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--ds-ink: #14181c`, `--ds-teal: #1a5c66`, `--ds-mist: #eef3f4`, `--ds-line: #c5cbce`, `--ds-amber: #a67a30`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft mist-field atmosphere
