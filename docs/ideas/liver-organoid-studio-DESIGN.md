# Design — Liver Organoid Studio

## Brand
**Liver Organoid Studio** — soft-sim for multicellular liver organoid MASLD modelling. Never claim wet-lab validated organoid GMP manufacture, live patient transplant, or clinical MASLD diagnosis.

## Landing brief
- **Headline:** Grow the organoid. Match the liver.
- **Support:** Model packs for MASLD screening — compare multicellular HLOs against single-lineage HLC baselines before you lock a pack.
- **Primary CTA:** Open packs → `/packs`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not organoid GMP; not transplant; not clinical MASLD diagnosis; not authors’ system
- Sources: bioRxiv 10.64898/2026.06.02.729501 · authors’ code: none published

## Visual direction
- **Palette:** lab ink + hepatic rust + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--lo-ink: #14161a`, `--lo-rust: #8a4a3a`, `--lo-mist: #f1f0ed`, `--lo-line: #c8c6c1`, `--lo-teal: #2f6568`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft organoid mist
