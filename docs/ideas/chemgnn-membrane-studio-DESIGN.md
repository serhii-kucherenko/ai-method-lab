# Design — Chemgnn Membrane Studio

## Brand
**Chemgnn Membrane Studio** — soft-sim for GNN-guided CNT membrane design. Never claim wet-lab validated desalination membranes or live plant write-back.

## Landing brief
- **Headline:** Membranes designed as graphs, scored as surrogates.
- **Support:** Membrane packs with ChemGNN-style surrogates — compare against classical physics baselines before you lock a pack.
- **Primary CTA:** Open membranes → `/membranes`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not wet-lab validated; not live plant control; not authors’ system
- Sources: ChemRxiv 10.26434/chemrxiv.15006282 · authors’ code: none published

## Visual direction
- **Palette:** tube ink + brine teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--cm-ink: #141c22`, `--cm-teal: #2a7a8a`, `--cm-mist: #eef2f4`, `--cm-line: #c3c9ce`, `--cm-amber: #c4923a`
- **Typography:** Sora (display) + Source Sans 3 (body)
- Full-bleed hero with soft brine mist + faint tube-grid
