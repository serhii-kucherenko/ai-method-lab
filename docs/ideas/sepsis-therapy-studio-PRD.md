# PRD — Sepsis Therapy Studio

## Goal
Soft-sim studio where critical-care analytics leads compare continuous-time HMM antibiotic therapy effectiveness to static guideline baselines.

## Must-have (≥25)
Therapy pack CRUD, regimens, onsets, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Clinical diagnostic claims, live EHR write-back, FDA clearance, paper brand.
