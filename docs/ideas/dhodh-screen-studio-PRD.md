# PRD — Dhodh Screen Studio

## Goal
Soft-sim studio where antimalarial / compchem leads compare structure-based PfDHODH virtual screening to naive library baselines.

## Must-have (≥25)
Screen pack CRUD, hits, assays, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validation, clinical antimalarial advice, IND/NDA readiness, live compound procurement, paper brand.
