# Design — Crate Validate Studio

## Brand
**Crate Validate Studio** — soft-sim for ARC RO-Crate validation. Never claim production institutional repository write-back or live ARC farm control.

## Landing brief
- **Headline:** Crates that pass structure and substance.
- **Support:** Crate packs with structural + semantic validation — compare against metadata-only baselines before you lock a pack.
- **Primary CTA:** Open crates → `/crates`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not institutional repo write-back; not live ARC farm; not authors’ system
- Sources: BioHackrXiv zah28 · authors’ code: none published

## Visual direction
- **Palette:** crate ink + validate teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--cv-ink: #152028`, `--cv-teal: #2d7a78`, `--cv-mist: #eef2f3`, `--cv-line: #c3cacd`, `--cv-amber: #c4923a`
- **Typography:** Outfit (display) + Source Sans 3 (body)
- Full-bleed hero with soft crate mist + faint schema-grid
