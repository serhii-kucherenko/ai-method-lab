# Design — Enorms Baseline Studio

## Brand
**Enorms Baseline Studio** — soft-sim for patient-specific EEG baselines. Never claim clinical diagnostic use, live EEG device control, or FDA clearance.

## Landing brief
- **Headline:** Baselines that belong to the patient.
- **Support:** Baseline packs with E-norms patient-specific EEG norms — compare against population baselines before you lock a pack.
- **Primary CTA:** Open baselines → `/baselines`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not diagnostic; not live EEG control; not FDA cleared; not authors’ system
- Sources: medRxiv 10.64898/2026.07.13.26357876 · authors’ code: none published

## Visual direction
- **Palette:** cortex ink + synapse teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--eb-ink: #161c24`, `--eb-teal: #2a7a88`, `--eb-mist: #eef2f4`, `--eb-line: #c3c9ce`, `--eb-amber: #c4923a`
- **Typography:** Literata (display) + Source Sans 3 (body)
- Full-bleed hero with soft cortex mist + faint EEG-grid
