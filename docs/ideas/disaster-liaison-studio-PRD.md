# PRD — Disaster Liaison Studio

## Goal
Soft-sim studio where emergency-ops analytics leads compare pediatric-perinatal disaster liaison frameworks to generic disaster-headquarters baselines.

## Must-have (≥25)
Response pack CRUD, events, liaisons, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Live dispatch claims, clinical triage authority, government command systems, paper brand.
