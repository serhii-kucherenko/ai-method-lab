# Design — Track Map Studio

## Brand
**Track Map Studio** — soft-sim for online deformable SLAM in robotic surgery scenes. Never claim live robot control, clinical diagnostic use, or FDA clearance. Not Track2Map.

## Landing brief
- **Headline:** Map the deforming field without waiting for a perfect prior.
- **Support:** Track packs for intraoperative reconstruction — compare online deformable SLAM against offline kinematics-prior baselines before you lock a pack.
- **Primary CTA:** Open tracks → `/tracks`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not live robot control; not diagnostic; not FDA cleared; not authors’ system; not Track2Map
- Sources: arXiv 2607.08408 · authors’ code: none published

## Visual direction
- **Palette:** field ink + track teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--tm-ink: #171c22`, `--tm-teal: #2a6f6a`, `--tm-mist: #eef2f4`, `--tm-line: #c3c9ce`, `--tm-amber: #c4923a`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft deformable mesh mist
