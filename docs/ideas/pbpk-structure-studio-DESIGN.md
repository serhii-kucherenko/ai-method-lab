# Design — PBPK Structure Studio

## Brand
**PBPK Structure Studio** — soft-sim for topology-compiled structure-only PBPK. Never claim regulatory PK filing or live LIMS.

## Landing brief
- **Headline:** Whole-body PK from structure alone.
- **Support:** Compound packs with topology-compiled PBPK — compare against measured-lab baselines before you lock a pack.
- **Primary CTA:** Open compounds → `/compounds`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not regulatory filing; not live LIMS; not authors’ system
- Sources: ChemRxiv 10.26434/chemrxiv.15004452 · authors’ code: none published

## Visual direction
- **Palette:** pharma ink + soft violet-avoided teal + porcelain (not purple glow, not cream-terracotta, not broadsheet)
  - `--pb-ink: #152028`, `--pb-teal: #2f7a72`, `--pb-porcelain: #eef2f3`, `--pb-line: #c4cbd0`, `--pb-amber: #c4923a`
- **Typography:** Manrope (display) + IBM Plex Sans (body)
- Full-bleed hero with soft porcelain mist + faint topology-grid
