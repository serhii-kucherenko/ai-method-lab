# Design — Chem Trace Studio

## Brand
**Chem Trace Studio** — soft-sim for typed trace-state validation of agentic chemistry workflows. Never claim certified compliance or live HPC job control.

## Landing brief
- **Headline:** Chemistry agents that leave a checkable trail.
- **Support:** Workflow packs with typed trace-state gates — compare against ungated agent baselines before you lock a pack.
- **Primary CTA:** Open workflows → `/workflows`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not certified compliance; not live HPC; not authors’ system
- Sources: ChemRxiv 10.26434/chemrxiv.15006307 · authors’ code: none published

## Visual direction
- **Palette:** lab charcoal + signal teal + cool chalk (not purple, not cream-terracotta, not broadsheet)
  - `--ct-ink: #171d22`, `--ct-teal: #2a7f7a`, `--ct-chalk: #eef1f3`, `--ct-line: #c3c9ce`, `--ct-amber: #c4923a`
- **Typography:** Outfit (display) + Source Sans 3 (body)
- Full-bleed hero with soft chalk mist + faint trace-grid
