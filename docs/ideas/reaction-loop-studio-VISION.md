# Vision — Reaction Loop Studio

## Problem
Open-loop VLM condition pickers drift without chemist gates. Teams lack a soft-sim bench that compares chemist-in-the-loop VLM agents to open-loop baselines before locking a campaign pack.

## Buyer
Process chemistry / manufacturing eng leads.

## Promise
Version campaign packs, configure reagent spaces and loop policies, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not a chem-trace or assay-guard desk. Domain nouns: campaigns, reagents, loops, runs, compares.
