# Vision — Feature Sufficiency Studio

## Problem
Clinical ML models are often trained on rich feature sets, then deployed where patients only have partial observations. Teams lack a bench that shows when a partial mask is still “enough” versus when it silently underperforms the full-feature baseline.

## Buyer
Healthcare AI / clinical model-ops leads who already buy eval benches.

## Promise
Feature Sufficiency Studio lets them version feature packs and observation masks, run sufficiency checks against a full-feature baseline, and see deltas on a scoreboard — as a method-lab soft-sim, not a clinical device.

## Differentiation
Not a persona/triage desk. Not jobs/lifecycle shells. Domain nouns are features, masks, cohorts, sufficiency runs, and partial-vs-full compares.
