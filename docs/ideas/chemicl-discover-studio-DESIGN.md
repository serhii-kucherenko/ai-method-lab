# Design — Chemicl Discover Studio

## Brand
**Chemicl Discover Studio** — soft-sim for multimodal chemistry in-context learning. Never claim wet-lab validated discovery or live ELN write-back.

## Landing brief
- **Headline:** Chemistry context that sees more than text.
- **Support:** Discover packs with multimodal in-context learning — compare against text-only ICL baselines before you lock a pack.
- **Primary CTA:** Open discovers → `/discovers`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not wet-lab validated; not live ELN; not authors’ system
- Sources: ChemRxiv 10.26434/chemrxiv.15006280 · authors’ code: none published

## Visual direction
- **Palette:** flask ink + reaction amber + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--cd-ink: #171c22`, `--cd-amber: #c4923a`, `--cd-mist: #eef2f4`, `--cd-line: #c3c9ce`, `--cd-teal: #2f7a7a`
- **Typography:** Outfit (display) + IBM Plex Sans (body)
- Full-bleed hero with soft flask mist + faint molecule-grid
