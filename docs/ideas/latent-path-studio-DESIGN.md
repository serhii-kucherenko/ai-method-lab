# Design — Latent Path Studio

## Brand
**Latent Path Studio** — soft-sim for multi-dimensional latent adolescent symptom trajectories. Never claim clinical diagnostic use, crisis intervention, or live EHR write-back.

## Landing brief
- **Headline:** See the path, not just one symptom score.
- **Support:** Cohort packs for adolescent mental-health analytics — compare multi-domain latent trajectories against single-domain baselines before you lock a pack.
- **Primary CTA:** Open packs → `/packs`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not clinical diagnostic; not crisis intervention; not live EHR write-back; not authors’ study brand
- Sources: PsyArXiv ed5nq · authors’ code: none published

## Visual direction
- **Palette:** path ink + cohort teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--lp-ink: #151a22`, `--lp-teal: #2a6670`, `--lp-mist: #eef2f5`, `--lp-line: #c3c9ce`, `--lp-amber: #b8863a`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft trajectory-path mist
