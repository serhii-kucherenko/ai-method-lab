# Design — Omic Prior Studio

## Brand
**Omic Prior Studio** — soft-sim for statistical-priors-informed omics transformers. Never claim clinical diagnostic use, live EHR write-back, or FDA clearance. Not OmicFormer.

## Landing brief
- **Headline:** Put biological priors in the model, not only in the slide deck.
- **Support:** Omic packs for disease and complex-trait prediction — compare priors-informed transformers against priors-free baselines before you lock a pack.
- **Primary CTA:** Open omics → `/omics`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not diagnostic; not live EHR write-back; not FDA cleared; not authors’ system; not OmicFormer
- Sources: medRxiv 10.64898/2026.07.06.26357359 · authors’ code: none published

## Visual direction
- **Palette:** genome ink + prior teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--op-ink: #171c24`, `--op-teal: #2a6f6a`, `--op-mist: #eef2f4`, `--op-line: #c3c9ce`, `--op-amber: #c4923a`
- **Typography:** Literata (display) + Figtree (body)
- Full-bleed hero with soft prior-graph mist
