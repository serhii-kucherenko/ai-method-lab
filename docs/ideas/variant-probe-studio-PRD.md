# PRD — Variant Probe Studio

## Goal
Soft-sim studio where genomics leads compare interpretable genomic-FM probes to opaque pathogenicity baselines.

## Must-have (≥25)
Panel pack CRUD, probe configs, mechanism links, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Diagnostic clearance, live LIMS, paper brand.
