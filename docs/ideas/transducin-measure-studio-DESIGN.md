# Design — Transducin Measure Studio

## Brand
**Transducin Measure Studio** — soft-sim for coded OCT measurement recovery. Never claim clinical deployment, live PACS write-back, or diagnostic use.

## Landing brief
- **Headline:** Proprietary OCT measures, coded for care.
- **Support:** Measure packs that recover SNOMED-CT coded DICOM SRs — compare against raw private-tag dumps before you lock a pack.
- **Primary CTA:** Open measures → `/measures`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not clinical deployment; not live PACS; not diagnostic; not authors’ system
- Sources: medRxiv 10.64898/2026.07.14.26357256 · authors’ code: none published

## Visual direction
- **Palette:** retina ink + optic teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--tm-ink: #141c24`, `--tm-teal: #2a7d8c`, `--tm-mist: #eef2f4`, `--tm-line: #c3c9ce`, `--tm-amber: #c4923a`
- **Typography:** Literata (display) + Figtree (body)
- Full-bleed hero with soft retina mist + faint OCT-grid
