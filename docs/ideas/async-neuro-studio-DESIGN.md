# Design — Async Neuro Studio

## Brand
**Async Neuro Studio** — soft-sim for standardized video-based asynchronous neurological exams. Never claim clinical diagnostic use, live telehealth write-back, or FDA clearance. Never brand as VANE.

## Landing brief
- **Headline:** Run a consistent neuro exam when the clinician cannot be in the room.
- **Support:** Exam packs for multi-site AD/ADRD studies — compare standardized async video exams against ad-hoc baselines before you lock a pack.
- **Primary CTA:** Open packs → `/packs`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not clinical diagnostic; not live telehealth write-back; not FDA cleared; not authors’ VANE brand
- Sources: medRxiv 10.64898/2026.07.15.26357456 · authors’ code: none published

## Visual direction
- **Palette:** clinic ink + exam teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--an-ink: #14181f`, `--an-teal: #2a6a72`, `--an-mist: #eef3f5`, `--an-line: #c2c8cd`, `--an-amber: #b8873a`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft async-exam mist
