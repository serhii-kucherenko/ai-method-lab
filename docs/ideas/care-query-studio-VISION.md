# Vision — Care Query Studio

## Problem
Clinical LLM demos ignore multilingual point-of-care reality. Teams lack a soft-sim bench that compares LLM answers on frontline medical queries to local clinician baselines before locking a query pack.

## Buyer
Global-health / clinical LLM eval eng leads.

## Promise
Version query packs, configure locales and answer rubrics, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not a therapy-prompt or consult-bench desk clone. Domain nouns: queries, locales, answers, runs, compares.
