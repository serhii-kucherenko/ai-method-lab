# Vision — Sepsis Therapy Studio

## Problem
Microbiology that confirms antibiotic suitability often arrives after 72 hours, while sepsis needs effective therapy in the first hour. Teams lack a soft-sim bench that compares continuous-time HMM effectiveness models to static guideline baselines before locking a therapy pack.

## Buyer
Hospital analytics / critical-care decision-support eng leads.

## Promise
Version therapy packs, configure regimens and onset windows, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not a pv-causal or phe-escalate desk. Domain nouns: therapies, regimens, onsets, runs, compares.
