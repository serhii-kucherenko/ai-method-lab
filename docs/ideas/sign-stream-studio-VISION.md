# Vision — Sign Stream Studio

**Buyer:** Accessibility and language-access product leads who must decide whether sentence-level sign language translation can run as a real-time stream — not only as an offline batch gloss dump after the signer finishes.

**Outcome:** Register sign streams, segment sentences, set latency budgets, curate glossary coverage, and compare real-time stream quality against an offline-batch baseline before a team ships a brittle “wait for full clip” pipeline as accessibility policy.

**Why now:** arXiv 2607.09611 points toward real-time sentence-level sign language translation. Institutions buying language access need a studio for that stream-vs-batch decision pattern, not another generic caption desk.

**Honesty:** Method-lab soft-sim inspired by the paper’s real-time sentence-level translation direction. Not a live interpreter certification, not clinical ASL adjudication, not the authors’ production stack. Authors’ code: none published with the paper abstract we track.
