# PRD — Reaction Loop Studio

## Goal
Soft-sim studio where process chemists compare chemist-in-the-loop VLM reaction-condition agents to open-loop VLM baselines.

## Must-have (≥25)
Campaign pack CRUD, reagent spaces, loop policies, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Live wet-lab control, manufacturing clearance, paper brand.
