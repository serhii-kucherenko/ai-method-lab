# Webhook Retry Debt Studio — PRD

**Problem:** Platform and reliability leads enter incident reviews without a clear queue of failed and aging webhook deliveries by destination blast radius.  
**Solution:** Soft-sim studio that imports delivery inventories, classifies retry debt, and compares debt-aware path (A) vs ignore-backlog path (B).  
**Success:** ≥25 features; ≥11 pages including `/`, `/pricing`, `/demo`, `/onboarding`, `/flows`; dual-impl ≥30 goldens; live app smoke.  
**Out of scope:** Live broker rewrite; feature-flag debt; schema migration packs; clinical/device/wet-lab.
