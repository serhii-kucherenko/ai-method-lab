# Design — Mhc Design Studio

## Brand
**Mhc Design Studio** — soft-sim for hybrid quantum–classical de novo MHC-binding peptide design. Never claim wet-lab validated binders, live ELN write-back, or FDA clearance.

## Landing brief
- **Headline:** Explore peptide space with a better prior than luck.
- **Support:** Peptide packs for MHC-binding design — compare hybrid quantum–classical de novo against classical generative baselines before you lock a pack.
- **Primary CTA:** Open peptides → `/peptides`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not wet-lab validated; not live ELN write-back; not FDA cleared; not authors’ system
- Sources: bioRxiv 10.64898/2026.07.09.736951 · authors’ code: none published

## Visual direction
- **Palette:** allele ink + design teal + cool mist (not purple, not cream-terracotta, not broadsheet)

- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft sequence-space mist
