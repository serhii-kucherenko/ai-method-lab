# PRD — World Cog Drive Studio

## Goal
Soft-sim studio where autonomy leads compare dual-level world-cognitive VLA driving to single-level VLA baselines.

## Must-have (≥25)
Route pack CRUD, world configs, action policies, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Certified AV, live vehicle control, paper brand.
