# Vision — Phe Escalate Studio

## Problem
Manual outbreak triage is slow and inconsistent. Teams lack a soft-sim bench that compares AI-assisted classification and escalation to manual triage baselines before locking an escalate pack.

## Buyer
Public-health emergency / surveillance ops eng leads.

## Promise
Version escalate packs, configure classifications and thresholds, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not a sovereign-cost or governed-research desk. Domain nouns: escalates, classifications, thresholds, runs, compares.
