# PRD — Tubule Mps Studio

## Goal
Soft-sim studio where MPS analytics leads compare voclosporin mitochondrial preservation to cyclosporine A baselines in proximal-tubule packs.

## Must-have (≥25)
Tubule pack CRUD, regimens, assays, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab MPS validation, transplant dosing advice, IND/NDA readiness, live patient care, paper brand.
