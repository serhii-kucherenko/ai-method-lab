# Design — Pestwin Control Studio

## Brand
**Pestwin Control Studio** — soft-sim for modular pest/vector agent control. Never claim field-validated eradication or live spray-fleet write-back.

## Landing brief
- **Headline:** Pest control that thinks in agents.
- **Support:** Control packs with modular multi-agent simulations — compare against single-species baselines before you lock a pack.
- **Primary CTA:** Open controls → `/controls`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not field-validated; not live spray-fleet; not authors’ system
- Sources: arXiv 2607.09420 · authors’ code: none published

## Visual direction
- **Palette:** canopy ink + vector green + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--pc-ink: #162018`, `--pc-green: #3a7a4a`, `--pc-mist: #eef2ef`, `--pc-line: #c4cbc6`, `--pc-amber: #c4923a`
- **Typography:** Fraunces (display) + DM Sans (body)
- Full-bleed hero with soft canopy mist + faint agent-grid
