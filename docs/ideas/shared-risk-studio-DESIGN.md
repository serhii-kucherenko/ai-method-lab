# Design — Shared Risk Studio

## Brand
**Shared Risk Studio** — soft-sim for shared multi-disease health representations. Never claim CDS clearance or live EHR.

## Landing brief
- **Headline:** One representation. Many disease horizons.
- **Support:** Cohort packs with shared risk queries — compare against disease-specific baselines before you lock a pack.
- **Primary CTA:** Open cohorts → `/cohorts`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not CDS cleared; not live EHR; not authors’ system
- Sources: medRxiv 10.64898/2026.07.07.26357373 · authors’ code: none published

## Visual direction
- **Palette:** biobank navy + soft mint + cool paper (not purple, not cream-terracotta, not broadsheet)
  - `--sr-ink: #142033`, `--sr-mint: #3a8f7a`, `--sr-paper: #eef2f4`, `--sr-line: #c2c9d0`, `--sr-coral: #c45a5a`
- **Typography:** Literata (display) + Source Sans 3 (body)
- Full-bleed hero with soft paper mist + faint risk-grid
