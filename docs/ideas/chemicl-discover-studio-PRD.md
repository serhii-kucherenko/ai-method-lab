# PRD — Chemicl Discover Studio

## Goal
Soft-sim studio where chem-ML leads compare multimodal ChemICL to text-only ICL baselines for chemistry discovery.

## Must-have (≥25)
Discover pack CRUD, exemplars, modalities, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validation, live ELN write-back, paper brand.
