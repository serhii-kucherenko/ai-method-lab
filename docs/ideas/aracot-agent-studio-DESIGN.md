# Design — Aracot Agent Studio

## Brand
**Aracot Agent Studio** — soft-sim for Arabic CoT agent distillation. Never claim production Arabic LLM deployment or live customer chat write-back.

## Landing brief
- **Headline:** Arabic agents that reason in steps.
- **Support:** Agent packs with chain-of-thought distillation — compare against non-distilled multilingual baselines before you lock a pack.
- **Primary CTA:** Open agents → `/agents`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not production LLM deployment; not live chat write-back; not authors’ system
- Sources: Research Square rs-10196257 · authors’ code: none published

## Visual direction
- **Palette:** ink charcoal + date palm green + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--aa-ink: #1a1f24`, `--aa-green: #3a7a5a`, `--aa-mist: #eef2f0`, `--aa-line: #c4cac7`, `--aa-amber: #c4923a`
- **Typography:** Literata (display) + Figtree (body)
- Full-bleed hero with soft palm mist + faint step-grid
