# PRD — Therapy Prompt Studio

## Goal
Soft-sim studio where LLM safety leads compare structured therapy-safety gates to prompt-only baselines on high-risk psychiatric scenarios.

## Must-have (≥25)
Prompt pack CRUD, scenarios, gates, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Clinical therapy claims, crisis hotline replacement, live patient chat write-back, FDA clearance, paper brand.
