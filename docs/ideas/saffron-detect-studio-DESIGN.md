# Design — Saffron Detect Studio

## Brand
**Saffron Detect Studio** — soft-sim for CNN stigma-image adulteration detection. Never claim field-validated customs authority, live supply-chain write-back, or certified lab accreditation.

## Landing brief
- **Headline:** Spot counterfeit stigmas before the batch ships.
- **Support:** Detect packs for saffron authenticity — compare CNN stigma-image detection against visual inspection baselines before you lock a pack.
- **Primary CTA:** Open detects → `/detects`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not certified lab accreditation; not live customs write-back; not authors’ system
- Sources: Research Square / DOI 10.21203/rs.3.rs-10292094 · authors’ code: none published

## Visual direction
- **Palette:** stigma ink + saffron amber + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--sd-ink: #1c1712`, `--sd-amber: #c4842a`, `--sd-mist: #f3efe8`, `--sd-line: #d2c8b8`, `--sd-teal: #3a6f6a`
- **Typography:** Libre Baskerville (display) + Source Sans 3 (body)
- Full-bleed hero with soft stigma-thread mist
