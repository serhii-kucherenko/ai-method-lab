# PRD — Mhc Design Studio

## Goal
Soft-sim studio where immuno design leads compare hybrid quantum–classical de novo MHC peptide design to classical generative baselines.

## Must-have (≥25)
Peptide pack CRUD, alleles, designs, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validated binder claims, live ELN write-back, FDA clearance, paper brand.
