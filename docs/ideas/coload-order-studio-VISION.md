# Vision — Coload Order Studio

## Problem
Simultaneous co-loading of chemo and photothermal agents into hollow mesoporous carriers can waste encapsulation efficiency. Teams lack a soft-sim bench that compares ordered load sequences to simultaneous baselines before locking a carrier pack.

## Buyer
Nanomedicine / formulation analytics eng leads.

## Promise
Version carrier packs, configure load sequences and assays, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not a nanodomain-target or liver-organoid desk. Domain nouns: packs, carriers, loads, assays, runs, compares.
