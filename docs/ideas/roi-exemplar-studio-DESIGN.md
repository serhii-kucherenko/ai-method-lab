# Design — Roi Exemplar Studio

## Brand
**Roi Exemplar Studio** — soft-sim for optimized VLM in-context ROI exemplars. Never claim clinical diagnostic use or live PACS write-back.

## Landing brief
- **Headline:** Exemplars that teach the model where to look.
- **Support:** Exemplar packs for region-of-interest selection — compare optimized in-context sets against naive baselines before you lock a pack.
- **Primary CTA:** Open exemplars → `/exemplars`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not diagnostic; not live PACS; not authors’ system
- Sources: iScience 10.1016/j.isci.2026.116518 · authors’ code: none published

## Visual direction
- **Palette:** scan ink + roi coral + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--re-ink: #1a1f28`, `--re-coral: #c45a4a`, `--re-mist: #eef1f4`, `--re-line: #c4c9cf`, `--re-teal: #2f7a7a`
- **Typography:** Sora (display) + DM Sans (body)
- Full-bleed hero with soft scan mist + faint ROI-grid
