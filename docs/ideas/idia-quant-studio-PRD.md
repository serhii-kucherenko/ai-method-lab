# PRD — Idia Quant Studio

## Goal
Soft-sim studio where proteomics leads compare informed DIA quantification to naive DIA baselines for single-cell regulatory proteins.

## Must-have (≥25)
Quant pack CRUD, spectra, targets, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validation, live instrument write-back, paper brand.
