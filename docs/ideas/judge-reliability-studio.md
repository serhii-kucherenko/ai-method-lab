# Judge Reliability Studio

**State:** framed  
**Slug:** `judge-reliability-studio`  
**Display name:** Judge Reliability Studio  
**Research seed:** [Diagnosing LLM-as-a-Judge via Item Response Theory](https://arxiv.org/abs/2602.00521)  
**Authors’ code:** none  

## Buyer

Platform / eval engineering leads who already run LLM-as-a-judge benches and need to know whether the judge is a stable measurement instrument — not only whether two judges agree.

## Outcome

Version judge packs, run item-response diagnostics (ability, difficulty, discrimination), flag unreliable items and unstable judges, and compare IRT-aware reliability gates against agreement-only baselines before locking a judge pack.

## Why this idea (business-first)

Pure software. Natural sequel to Rubric Compiler Studio. Matches biz-rubric-v2 prefer list (trust/eval). No device, clinical carepath, wet-lab, or retail novelty.

## Money hook

Eval seats + private judge/item packs + diagnostic run usage.

## Business score (draft)

Tier B candidate (~75): clear buyer + money; moat is IRT reliability vs agreement-only dashboards.

## Non-goals

Clinical judge skins, live production judge write-back, claiming certified psychometrics, desk-clone IA.
