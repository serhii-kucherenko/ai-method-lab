# PRD — Chemgnn Membrane Studio

## Goal
Soft-sim studio where membrane-ML leads compare ChemGNN surrogates to classical physics baselines for CNT desalination design.

## Must-have (≥25)
Membrane pack CRUD, graphs, surrogates, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab membrane validation, live plant write-back, paper brand.
