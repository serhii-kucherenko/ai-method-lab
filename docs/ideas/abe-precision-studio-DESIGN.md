# Design — Abe Precision Studio

## Brand
**Abe Precision Studio** — soft-sim for domain-insertion adenine base editor precision vs baseline ABE. Never claim wet-lab validation, IND/NDA readiness, patient dosing, or clinical gene-therapy advice.

## Landing brief
- **Headline:** Narrow the window. Compare the editor.
- **Support:** Editor packs for adenine base editing — compare domain-insertion ABE precision against baseline ABE before you lock a pack.
- **Primary CTA:** Open packs → `/packs`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not wet-lab validated; not IND/NDA ready; not patient dosing; not clinical gene-therapy advice; not authors’ brand
- Sources: bioRxiv 10.64898/2026.07.03.736350 · authors’ code: none published

## Visual direction
- **Palette:** helix ink + adenine teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--ap-ink: #14181c`, `--ap-teal: #1b5f6a`, `--ap-mist: #eef3f4`, `--ap-line: #c5cbce`, `--ap-amber: #a67a30`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft mist-field atmosphere
