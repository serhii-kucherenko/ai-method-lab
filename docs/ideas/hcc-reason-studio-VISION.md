# Vision — HCC Reason Studio

## Problem
Non-reasoning HCC risk tools miss pathway nuance. Teams lack a soft-sim bench that compares clinical-reasoning LLMs to non-reasoning baselines before locking a pathway pack.

## Buyer
Hepatology / oncology decision-support eng leads.

## Promise
Version pathway packs, configure reasoners, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not an MRI-report or CVD-federation desk. Domain nouns: pathways, schemas, reasoners, runs, compares.
