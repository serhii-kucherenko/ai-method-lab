# Vision — Crate Validate Studio

## Problem
Metadata-only RO-Crate validators miss broken payloads. Teams lack a soft-sim bench that compares structural+semantic ARC validation to metadata-only baselines before locking a crate pack.

## Buyer
Research-data / FAIR tooling eng leads.

## Promise
Version crate packs, configure rules and checks, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not a governance or assay desk. Domain nouns: crates, rules, checks, runs, compares.
