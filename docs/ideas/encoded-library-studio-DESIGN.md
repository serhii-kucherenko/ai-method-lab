# Design — Encoded Library Studio

## Brand
**Encoded Library Studio** — soft-sim for iterative DNA-encoded library construct-and-screen cycles. Never claim wet-lab validated IND/NDA, live screening robotics, or clinical candidate nomination.

## Landing brief
- **Headline:** Iterate the library. Lock the hit.
- **Support:** Library packs for macrocyclic discovery — compare iterative DELT construct-and-screen cycles against single-pass screens before you lock a hit pack.
- **Primary CTA:** Open packs → `/packs`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not wet-lab validated; not IND/NDA; not live robotics; not authors’ system
- Sources: ChemRxiv 10.26434/chemrxiv.15004709 · authors’ code: none published

## Visual direction
- **Palette:** lab ink + sea teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--el-ink: #12181e`, `--el-sea: #1f6b6e`, `--el-mist: #eef2f3`, `--el-line: #c4cacf`, `--el-copper: #a8743c`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft encoded-strand mist
