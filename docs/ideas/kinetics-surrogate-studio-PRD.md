# PRD — Kinetics Surrogate Studio

## Goal
Soft-sim studio where combustion leads compare entropy-constrained kinetics surrogates to full-rate baselines.

## Must-have (≥25)
Chemistry pack CRUD, rate tables, surrogate configs, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Certified CFD, live plant, paper brand.
