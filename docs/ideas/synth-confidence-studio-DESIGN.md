# Design — Synth Confidence Studio

## Brand
**Synth Confidence Studio** — soft-sim for confidence-gated AI retrosynthesis. Never claim wet-lab validated manufacturing routes or live ELN.

## Landing brief
- **Headline:** AI routes that earn a confidence score.
- **Support:** Route packs with confidence-gated retrosynthesis — compare against naive AI baselines before you lock a pack.
- **Primary CTA:** Open routes → `/routes`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not wet-lab validated; not live ELN; not authors’ system
- Sources: ChemRxiv 10.26434/chemrxiv.15006146 · authors’ code: none published

## Visual direction
- **Palette:** flask ink + confidence green + cool parchment (not purple, not cream-terracotta, not broadsheet)
  - `--sc-ink: #161b20`, `--sc-green: #3a8a5a`, `--sc-parchment: #eef1f3`, `--sc-line: #c3c9ce`, `--sc-amber: #c4923a`
- **Typography:** Manrope (display) + Source Sans 3 (body)
- Full-bleed hero with soft parchment mist + faint route-grid
