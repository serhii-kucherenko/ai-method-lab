# Design — Pore Inverse Studio

## Brand
**Pore Inverse Studio** — soft-sim for unified nanoporous inverse design. Never claim certified materials performance or live plant control.

## Landing brief
- **Headline:** Inverse-design pores that earn the compare.
- **Support:** Materials packs with unified inverse design — compare against naive generative baselines before you lock a pack.
- **Primary CTA:** Open materials → `/materials`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not certified performance; not live plant; not authors’ system
- Sources: ChemRxiv 10.26434/chemrxiv.15005975 · authors’ code: none published

## Visual direction
- **Palette:** graphite ink + pore aqua + cool ash (not purple, not cream-terracotta, not broadsheet)
  - `--pi-ink: #161c22`, `--pi-aqua: #2f8a8f`, `--pi-ash: #e9eef0`, `--pi-line: #c2c9ce`, `--pi-copper: #b87a48`
- **Typography:** Sora (display) + DM Sans (body)
- Full-bleed hero with soft ash mist + faint pore-grid
