# Delegation Expiry Studio — PRD

**Problem:** Agent tool access is granted permanently or ad hoc, so blast radius grows until an incident.  
**Solution:** Soft-sim studio to create TTL delegation grants, auto-expire them, and keep an audit ledger; compare TTL path (A) vs permanent-scope path (B).  
**Success:** ≥25 features; ≥11 pages including commercial routes; dual-impl ≥30 goldens; live app smoke.  
**Out of scope:** Live agent runtime kernel; raw cloud IAM wrapper; Tool Scope static matrices as the only surface; OT bypass tickets.
