# Design — Idia Quant Studio

## Brand
**Idia Quant Studio** — soft-sim for informed DIA single-cell proteomics. Never claim wet-lab validated proteomics or live instrument write-back.

## Landing brief
- **Headline:** Single-cell proteins that informed DIA can see.
- **Support:** Quant packs for regulatory-protein quantification — compare informed DIA against naive DIA baselines before you lock a pack.
- **Primary CTA:** Open quants → `/quants`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not wet-lab validated; not live instrument control; not authors’ system
- Sources: bioRxiv 10.1101/2025.05.30.656945 · authors’ code: none published

## Visual direction
- **Palette:** ion ink + spectrum teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--iq-ink: #151c24`, `--iq-teal: #2a7a88`, `--iq-mist: #eef2f4`, `--iq-line: #c3c9ce`, `--iq-amber: #c4923a`
- **Typography:** Sora (display) + Source Sans 3 (body)
- Full-bleed hero with soft ion mist + faint spectrum-grid
