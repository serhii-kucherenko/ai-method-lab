# Design — Molecule Sample Studio

## Brand
**Molecule Sample Studio** — soft-sim for sample-efficient generative molecular design. Never claim wet-lab validation or live ELN.

## Landing brief
- **Headline:** Fewer samples. Stronger campaigns.
- **Support:** Campaign packs with sample-efficient optimizers — compare against naive generative baselines before you lock a pack.
- **Primary CTA:** Open campaigns → `/campaigns`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not wet-lab validated; not live ELN; not authors’ system
- Sources: arXiv 2607.12488 · authors’ code: none published

## Visual direction
- **Palette:** lab indigo-slate + chartreuse accent + cool porcelain (not purple glow, not cream-terracotta, not broadsheet)
  - `--ms-ink: #121826`, `--ms-accent: #7a9e2f`, `--ms-porcelain: #eef1f4`, `--ms-line: #c5ccd6`, `--ms-teal: #3d6b72`
- **Typography:** Outfit (display) + IBM Plex Sans (body)
- Full-bleed hero with soft porcelain mist + faint sample-grid
