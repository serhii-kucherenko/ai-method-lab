# Vision — Molecule Sample Studio

## Problem
Naive generative campaigns burn samples. Teams lack a soft-sim bench that compares sample-efficient generative optimization to naive generative baselines before locking a campaign pack.

## Buyer
Medicinal chemistry / generative design eng leads.

## Promise
Version campaign packs, configure optimizers, run dual compares, lock when sample-efficiency deltas are understood — method-lab soft-sim only.

## Differentiation
Not a developable-molecule or quantum-kernel desk. Domain nouns: campaigns, targets, optimizers, runs, compares.
