# Design — Pv Causal Studio

## Brand
**Pv Causal Studio** — soft-sim for target-trial causal pharmacovigilance signals. Never claim regulatory submission authority, live claims write-back, or FDA clearance.

## Landing brief
- **Headline:** Catch the adverse signal with a defined population, not only a tip line.
- **Support:** Pv packs for proactive signal detection — compare target-trial emulations against spontaneous-reporting baselines before you lock a pack.
- **Primary CTA:** Open signals → `/signals`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not regulatory submission; not live claims write-back; not FDA cleared; not authors’ system
- Sources: medRxiv 10.64898/2026.07.01.26356874 · authors’ code: none published

## Visual direction
- **Palette:** vigilance ink + causal teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--pc-ink: #171c24`, `--pc-teal: #2a6f6a`, `--pc-mist: #eef2f4`, `--pc-line: #c3c9ce`, `--pc-amber: #c4923a`
- **Typography:** Literata (display) + Figtree (body)
- Full-bleed hero with soft cohort-timeline mist
