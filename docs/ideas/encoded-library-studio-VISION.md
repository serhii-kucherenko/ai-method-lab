# Vision — Encoded Library Studio

## Problem
Single-pass DNA-encoded library screens dump huge hit lists without an iterative construct–screen–optimize loop. Teams lack a soft-sim bench that compares iterative DELT cycles to single-pass baselines before locking a hit pack.

## Buyer
Drug-discovery / DELT chemistry analytics eng leads.

## Promise
Version library packs, configure construct cycles and hit filters, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not a probe-domain or molecule-sample desk. Domain nouns: packs, libraries, cycles, hits, assays, runs, compares.
