# PRD — Usher Dual Studio

## Goal
Soft-sim studio where gene-therapy analytics leads compare MYO7A gene supplementation to Myo7b activation for Usher syndrome 1B pathway planning.

## Must-have (≥25)
Allele pack CRUD, vectors, assays, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validation, IND/NDA readiness, patient dosing, clinical gene-therapy advice, paper brand.
