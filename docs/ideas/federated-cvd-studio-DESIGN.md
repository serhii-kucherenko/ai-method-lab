# Design — Federated CVD Studio

## Brand
**Federated CVD Studio** — soft-sim for privacy-preserving CVD risk federations. Never claim FDA clearance or live EHR write-back.

## Landing brief
- **Headline:** Federated risk scores that survive the compare.
- **Support:** Cohort packs with federation configs — compare against centralized baselines before you lock a pack.
- **Primary CTA:** Open cohorts → `/cohorts`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not FDA cleared; not live EHR; not authors’ system
- Sources: arXiv 2607.08595 · authors’ code: none published

## Visual direction
- **Palette:** cardio navy + pulse rose + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--fc-ink: #0f1c2e`, `--fc-rose: #c45a6a`, `--fc-mist: #e8eef4`, `--fc-line: #b7c4d1`, `--fc-teal: #2f6f73`
- **Typography:** Literata (display) + DM Sans (body)
- Full-bleed hero with soft mist + faint federation-grid
