# Comprehensive blueprint — Feature Sufficiency Studio

## Buyer story
An eval lead opens a feature pack, defines observation masks, runs partial vs full sufficiency scoring, and only locks the pack when deltas are understood.

## Required routes
`/`, `/pricing`, `/demo`, `/onboarding`, `/flows`, `/features`, `/masks`, `/cohorts`, `/sufficiency`, `/compare`, `/scoreboard`, `/settings`, `/honesty`

## Flows (≥5)
1. Create feature pack  
2. Define observation mask  
3. Add cohort case  
4. Run A/B sufficiency compare  
5. Export + webhook  

## Anti-clone
No `/jobs` `/lifecycle` `/scenario` shells. Distinct clinical-ML-eval IA.
