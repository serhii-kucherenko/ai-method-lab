# PRD — Retro Route Studio

## Problem
Synthesis-planning leads waste cycles on greedy single-step suggestions that forget failed branches and intermediate properties. They need a studio that keeps structured search memory across a multi-step route campaign.

## Goals
1. Register versioned route packs and multi-step candidate routes.
2. Maintain a structured search-memory board (tried routes + intermediate properties).
3. Compare agentic structured-memory scoring (A) vs naive local/greedy search (B).
4. Ship scoreboard, audit, export, org/settings, pricing/demo/onboarding, ≥5 flows.

## Non-goals
- Branding as RetroAgent
- Wet-lab execution or regulatory synthesis certification
- Desk shell noun-swap (`/jobs` `/lifecycle` `/scenario` `/batch` `/goldens`)
- Crystal Bind / Developable Molecule IA clone

## Dual score
| Profile | Meaning |
|---------|---------|
| **A — structured memory** | Rewards global search-state use: tried-route recall, intermediate coverage, branch avoidance |
| **B — naive local** | Rewards greedy single-step fluency without global memory |

## Success metrics
- ≥25 features, ≥11 pages, ≥5 named flows, ≥30 goldens, build + app-up green
- Stranger can finish onboarding → pack → route → memory → compare without docs

## Money honesty
Hypothetical bench seats + private route packs. Method-lab packaging; no live checkout required.
