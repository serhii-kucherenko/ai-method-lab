# Schema Drift Studio — Vision

Live databases quietly drift from the last approved migration pack until a release gate becomes archaeology. Schema Drift Studio soft-sims **approved pack matched to live schema** versus a live-as-is baseline so platform leads open the gate with a drift evidence pack, not a migration-tool console dump.

**Refuse to become:** Flyway/Liquibase UI clone, live prod migrator, Online Diff (OT PLC), Stale Flag (feature flags), or desk jobs/lifecycle shell.
