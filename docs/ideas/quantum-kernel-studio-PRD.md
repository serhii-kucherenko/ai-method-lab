# PRD — Quantum Kernel Studio

## Goal
Soft-sim studio where chem-informatics leads compare quantum multiple-kernel QSAR plans to classical kernel baselines.

## Must-have (≥25)
Molecule pack CRUD, kernel configs, targets, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Live quantum hardware, wet-lab, Q²SAR brand.
