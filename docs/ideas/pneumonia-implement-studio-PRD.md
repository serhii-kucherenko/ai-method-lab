# PRD — Pneumonia Implement Studio

## Goal
Soft-sim studio where implementation leads compare CFIR co-designed childhood pneumonia primary-care models to status-quo pathway baselines.

## Must-have (≥25)
District pack CRUD, pathways, fidelity, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Live clinical triage, EMR write-back, government program authority, paper brand.
