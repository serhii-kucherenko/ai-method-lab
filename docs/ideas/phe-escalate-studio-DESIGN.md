# Design — Phe Escalate Studio

## Brand
**Phe Escalate Studio** — soft-sim for public-health emergency classification and escalation. Never claim operational deployment authority, live MoH write-back, or clinical diagnosis.

## Landing brief
- **Headline:** Escalate outbreaks with a scored assist.
- **Support:** Escalate packs for classification and escalation — compare AI-assisted paths against manual triage baselines before you lock a pack.
- **Primary CTA:** Open escalates → `/escalates`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not operational authority; not live MoH write-back; not diagnostic; not authors’ system
- Sources: medRxiv 10.64898/2026.07.07.26357475 · authors’ code: none published

## Visual direction
- **Palette:** alert ink + signal teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--pe-ink: #1a1f28`, `--pe-teal: #2a7a88`, `--pe-mist: #eef2f4`, `--pe-line: #c3c9ce`, `--pe-amber: #c4923a`
- **Typography:** Sora (display) + Source Sans 3 (body)
- Full-bleed hero with soft alert mist + faint escalate-grid
