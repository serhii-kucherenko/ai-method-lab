# Vision — Quantum Kernel Studio

## Problem
Classical QSAR kernels stall on hard binding landscapes. Teams lack a soft-sim bench that compares quantum multiple-kernel plans to classical kernels before locking a pack.

## Buyer
Computational chemistry / chem-informatics leads.

## Promise
Version molecule packs, configure kernels, run dual compares, lock when deltas are understood — method-lab soft-sim only.

## Differentiation
Not a retrosynthesis route desk and not a wet-lab generator. Domain nouns: molecules, kernels, targets, runs, compares.
