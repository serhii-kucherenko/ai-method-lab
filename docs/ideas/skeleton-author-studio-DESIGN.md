# Design — Skeleton Author Studio

## Brand
**Skeleton Author Studio** — soft-sim for visual authoring of non-visual data experiences. Never claim WCAG certification or live screen-reader OEM.

## Landing brief
- **Headline:** Author the path before the reader hears it.
- **Support:** Experience packs with navigation skeletons — compare against naive linear baselines before you lock a pack.
- **Primary CTA:** Open experiences → `/experiences`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not WCAG certified; not live screen-reader OEM; not authors’ system
- Sources: arXiv 2607.14579 · authors’ code: none published

## Visual direction
- **Palette:** charcoal guide + soft lime focus + cool paper (not purple, not cream-terracotta, not broadsheet)
  - `--sa-ink: #1a1f24`, `--sa-lime: #8faf3a`, `--sa-paper: #f0f2f4`, `--sa-line: #c4cacf`, `--sa-blue: #3a6f8f`
- **Typography:** Space Grotesk (display) + Source Sans 3 (body)
- Full-bleed hero with soft paper mist + faint skeleton-grid
