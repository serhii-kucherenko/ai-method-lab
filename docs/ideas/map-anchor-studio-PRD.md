# PRD — Map Anchor Studio

## Goal
Soft-sim studio where antiviral biologics analytics leads compare mucus-anchoring MAP antibody conjugates to conventional monoclonal antibodies.

## Must-have (≥25)
Conjugate pack CRUD, anchors, assays, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validation, clinical antiviral advice, IND/NDA readiness, live patient dosing, paper brand.
