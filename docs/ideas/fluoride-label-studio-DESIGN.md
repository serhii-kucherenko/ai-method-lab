# Design — Fluoride Label Studio

## Brand
**Fluoride Label Studio** — soft-sim for fast isotopic fluorine-18 exchange labeling. Never claim wet-lab validated radiopharmaceutical GMP batch release, live cyclotron control, or clinical PET dosing.

## Landing brief
- **Headline:** Swap the fluoride. Skip the prosthetic.
- **Support:** Label packs for PET tracer chemistry — compare fast isotopic exchange against multistep prosthetic baselines before you lock a pack.
- **Primary CTA:** Open packs → `/packs`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not GMP batch release; not live cyclotron; not clinical PET dosing; not authors’ system
- Sources: ChemRxiv 10.26434/chemrxiv.15005804 · authors’ code: none published

## Visual direction
- **Palette:** lab ink + cobalt teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--fl-ink: #12161c`, `--fl-cobalt: #2a5f7a`, `--fl-mist: #eef2f5`, `--fl-line: #c3c9cf`, `--fl-amber: #b4833a`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft fluorine-exchange mist
