# Design — Access Equity Studio

## Brand
**Access Equity Studio** — soft-sim for equity-access autism AI screening pathways. Never claim clinical diagnostic use, live EHR write-back, or FDA clearance.

## Landing brief
- **Headline:** Accuracy without access is not a win.
- **Support:** Pathway packs for autism digital screening — compare equity-access designs against accuracy-only baselines before you lock a pack.
- **Primary CTA:** Open packs → `/packs`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not clinical diagnostic; not live EHR write-back; not FDA cleared; not authors’ review brand
- Sources: Frontiers DOI 10.3389/fpubh.2026.1898818 · authors’ code: none published

## Visual direction
- **Palette:** access ink + equity teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--ae-ink: #14191f`, `--ae-teal: #2a6a68`, `--ae-mist: #eef3f2`, `--ae-line: #c2c9c7`, `--ae-amber: #b8873a`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft access-pathway mist
