# PRD — Atlas Flow Studio

## Goal
Soft-sim studio where neuroimaging leads compare an integrated atlas registration + quantification workflow to fragmented multi-tool baselines.

## Must-have (≥25)
Atlas pack CRUD, registrations, quantifications, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Live microscope control, clinical diagnostic claims, FDA clearance, NeuroFlow brand.
