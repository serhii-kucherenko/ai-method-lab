# Rubric Compiler Studio

**State:** framed  
**Slug:** `rubric-compiler-studio`  
**Display name:** Rubric Compiler Studio  
**Research seeds:** [RULERS](https://arxiv.org/abs/2601.08654), [Autorubric](https://arxiv.org/abs/2603.00077), [PReMISE](https://arxiv.org/abs/2605.30803)  
**Authors’ code:** none required — method synthesis, idea-first  

## Buyer

Platform / eval engineering leads and L&D / QA teams who already pay for LLM judges, benches, and review tooling — and keep shipping flaky holistic scores.

## Outcome

Author → lock/compile rubrics into executable criteria → score with evidence anchors → calibrate scales → audit reliability/validity → escalate when unsure. Domain (hiring, support, education) is a **skin**, not the product.

## Why this idea (business-first)

Software engineering can ship the whole loop. No device, wet-lab, hospital sales cycle, or retail novelty. Matches human steer 2026-07-26 and `docs/RESEARCH.md` scoring queue. Distinct from generic “agent eval desks” via **compile + evidence + calibration + selective trust**.

## Money hook

Team seats + per-score-run / private rubric packs. Optional enterprise rubric library.
