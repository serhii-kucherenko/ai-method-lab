# Vision — Kinetics Surrogate Studio

## Problem
Full chemical kinetics slows turbulent combustion sims. Teams lack a soft-sim bench that compares entropy-constrained surrogates to full-rate baselines before locking a chemistry pack.

## Buyer
Combustion / reacting-flow simulation eng leads.

## Promise
Version chemistry packs, configure surrogates, run dual compares, lock when deltas and entropy honesty are understood — method-lab soft-sim only.

## Differentiation
Not a drag-wall controller desk. Domain nouns: chemistry, rates, surrogates, runs, compares.
