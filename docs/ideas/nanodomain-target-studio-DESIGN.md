# Design — Nanodomain Target Studio

## Brand
**Nanodomain Target Studio** — soft-sim for localized troponin nanodomain targeting. Never claim wet-lab validated IND/NDA, live patient dosing, or clinical heart-failure diagnosis.

## Landing brief
- **Headline:** Target the nanodomain. Keep the squeeze.
- **Support:** Therapy packs for cardio precision design — compare localized nanodomain targeting against systemic phosphorylation baselines before you lock a pack.
- **Primary CTA:** Open packs → `/packs`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not IND/NDA; not live dosing; not clinical diagnosis; not authors’ system
- Sources: bioRxiv 10.1101/2025.11.18.689162 · authors’ code: none published

## Visual direction
- **Palette:** lab ink + cardio crimson + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--nt-ink: #14161b`, `--nt-crimson: #8b3a45`, `--nt-mist: #f0f1f3`, `--nt-line: #c5c8cd`, `--nt-teal: #2d6368`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft nanodomain mist
