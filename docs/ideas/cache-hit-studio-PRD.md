# PRD — Cache Hit Studio

## Goal
Soft-sim studio where discovery leads compare structured computational hit-finding to naive docking baselines.

## Must-have (≥25)
Hit pack CRUD, targets, compounds, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validated hit claims, live ELN write-back, FDA clearance, CACHE brand.
