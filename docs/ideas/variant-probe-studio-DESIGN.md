# Design — Variant Probe Studio

## Brand
**Variant Probe Studio** — soft-sim for interpretable genomic foundation-model probes. Never claim clinical diagnostic clearance or live LIMS.

## Landing brief
- **Headline:** Variant scores you can explain.
- **Support:** Panel packs with interpretable probes — compare against opaque pathogenicity baselines before you lock a pack.
- **Primary CTA:** Open panels → `/panels`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not diagnostic cleared; not live LIMS; not authors’ system
- Sources: bioRxiv 10.64898/2026.04.10.717844 · authors’ code: none published

## Visual direction
- **Palette:** genome ink + helix teal + cool paper (not purple, not cream-terracotta, not broadsheet)
  - `--vp-ink: #121820`, `--vp-teal: #2a7a7f`, `--vp-paper: #eef2f4`, `--vp-line: #c2c9cf`, `--vp-amber: #c4923a`
- **Typography:** Space Grotesk (display) + IBM Plex Sans (body)
- Full-bleed hero with soft paper mist + faint probe-grid
