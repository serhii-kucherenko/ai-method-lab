# PRD — Cardiac Pocus Studio

## Goal
Soft-sim studio where POCUS analytics leads compare cardiac POCUS COPD detection patterns to lung-ultrasound baselines.

## Must-have (≥25)
Exam pack CRUD, patterns, assays, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Live diagnostic clearance, clinical advice, PACS write-back, paper brand.
