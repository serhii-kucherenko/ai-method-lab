# Vision — Oncology Report Studio

## Problem
Single-model MRI report drafts miss rare oncology findings. Teams lack a soft-sim bench that compares multi-LLM collaborative drafting to single-LLM baselines before locking a report pack.

## Buyer
Neuro-oncology imaging / radiology AI eng leads.

## Promise
Version case packs, configure collaborators, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not a pathology-slide or cardiac-CT desk. Domain nouns: cases, schemas, collaborators, drafts, compares.
