# Vision — Immunize Impact Studio

## Problem

## Buyer

## Promise
Version impact packs, configure country panels and antigen coverage, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not an enhanced-flu or dengue-suit desk. Domain nouns: packs, countries, antigens, panels, runs, compares.
