# PRD — Pestwin Control Studio

## Goal
Soft-sim studio where vector-control leads compare modular multi-agent pest control to single-species baselines.

## Must-have (≥25)
Control pack CRUD, modules, populations, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Field eradication claims, live spray-fleet write-back, paper brand.
