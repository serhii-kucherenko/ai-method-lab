# PRD — Probe Domain Studio

## Goal
Soft-sim studio where assay-design leads compare cooperative multi-domain DNA probes to single-domain melting baselines.

## Must-have (≥25)
Probe pack CRUD, domains, targets, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validated diagnostic claims, live IVD clearance, whole-blood device deployment, paper brand.
