# Design — R2map Translate Studio

## Brand
**R2map Translate Studio** — soft-sim for T1W/T2W→R2map translation. Never claim clinical diagnostic use, live PACS write-back, or FDA clearance.

## Landing brief
- **Headline:** R2maps from the scans you already have.
- **Support:** Translate packs that turn T1W and T2W into R2maps — compare GAN translation against conventional R2 baselines before you lock a pack.
- **Primary CTA:** Open translates → `/translates`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not diagnostic; not live PACS; not FDA cleared; not authors’ system
- Sources: Medical Physics 10.1002/mp.70561 · authors’ code: none published

## Visual direction
- **Palette:** iron ink + map teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--r2-ink: #171c24`, `--r2-teal: #2f7a8a`, `--r2-mist: #eef2f4`, `--r2-line: #c3c9ce`, `--r2-amber: #c4923a`
- **Typography:** Sora (display) + IBM Plex Sans (body)
- Full-bleed hero with soft iron mist + faint map-grid
