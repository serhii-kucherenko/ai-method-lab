# Design — Assay Guard Studio

## Brand
**Assay Guard Studio** — soft-sim for assay-aware liquid-handling protocol validation. Never claim certified compliance or live robot control.

## Landing brief
- **Headline:** Protocols that pass the assay gate.
- **Support:** Deck packs with assay-aware validators — compare against naive protocol runners before you lock a pack.
- **Primary CTA:** Open decks → `/decks`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not certified compliance; not live robot control; not authors’ system
- Sources: arXiv 2607.15620 · authors’ code: none published

## Visual direction
- **Palette:** sterile steel + pipette aqua + soft lab white (not purple, not cream-terracotta, not broadsheet)
  - `--ag-ink: #1b242c`, `--ag-aqua: #2a8f9a`, `--ag-white: #f2f5f7`, `--ag-line: #c5ced3`, `--ag-amber: #c48a2a`
- **Typography:** Sora (display) + Manrope (body)
- Full-bleed hero with soft lab white mist + faint deck-grid
