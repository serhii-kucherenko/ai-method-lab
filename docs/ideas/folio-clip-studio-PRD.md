# PRD — Folio Clip Studio

## Goal
Soft-sim studio where AgTech leads compare multimodal wearable plant-stress sensing to single-sensor baselines.

## Must-have (≥25)
Clip pack CRUD, sensor configs, stress runs, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Field farm validation, live greenhouse write-back, paper brand.
