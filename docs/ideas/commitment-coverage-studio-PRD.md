# Commitment Coverage Studio — PRD

**Problem:** FinOps renews cloud commitments without a clear $ view of under-coverage and unused commit versus on-demand spill.  
**Solution:** Soft-sim studio that imports commitment inventory + usage, computes coverage gaps in dollars, and compares commit-matched path (A) vs on-demand-blind path (B).  
**Success:** ≥25 features; ≥11 pages including `/`, `/pricing`, `/demo`, `/onboarding`, `/flows`; dual-impl ≥30 goldens; live app smoke.
