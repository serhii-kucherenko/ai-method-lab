# PRD — Dialogue Design Studio

## Goal
Soft-sim studio where civic-tech / T&S leads compare productive open-minded dialogue feed designs to engagement-maximizing baselines.

## Must-have (≥25)
Feed pack CRUD, badges, topics, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Live social network deployment, content moderation authority, election tooling, attitude-change clearance claims.
