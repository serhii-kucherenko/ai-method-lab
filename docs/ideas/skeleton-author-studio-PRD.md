# PRD — Skeleton Author Studio

## Goal
Soft-sim studio where accessibility leads compare scaffolded visual authoring of non-visual data experiences to naive linear baselines.

## Must-have (≥25)
Experience pack CRUD, navigation skeletons, label templates, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
WCAG certification, live screen-reader OEM, paper brand.
