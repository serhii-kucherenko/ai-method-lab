# Vision — Ion Hydrogel Studio

## Buyer

## Promise
Version gel packs, configure charge and salt runs, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not a fluoride-label or encoded-library desk. Domain nouns: packs, gels, charges, salts, assays, runs, compares.
