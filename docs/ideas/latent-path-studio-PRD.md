# PRD — Latent Path Studio

## Goal
Soft-sim studio where adolescent MH analytics leads compare multi-dimensional latent symptom trajectory classes to single-domain baselines.

## Must-have (≥25)
Cohort pack CRUD, predictors, trajectories, outcomes, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Clinical diagnostic claims, crisis intervention product, live EHR write-back, suicide-risk clearance.
