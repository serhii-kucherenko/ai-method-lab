# Vision — Pv Causal Studio

## Problem
Spontaneous reporting misses adverse drug events in older adults because of underreporting and no defined population. Teams lack a soft-sim bench that compares target-trial causal signal detection to spontaneous-reporting baselines before locking a pv pack.

## Buyer
Pharmacovigilance / RWE analytics eng leads.

## Promise
Version pv packs, configure cohorts and exposures, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not a nicu-ecg or phe-escalate desk. Domain nouns: signals, cohorts, exposures, runs, compares.
