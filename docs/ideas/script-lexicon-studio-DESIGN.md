# Design — Script Lexicon Studio

## Brand
**Script Lexicon Studio** — NLP soft-sim for Ge'ez-script lexicon expansion. Never brand as VEXMLM.

## Landing brief
- **Headline:** Expand the script so the model can hear it.
- **Support:** Language packs with Ge'ez-script lexicon expansions — compare against baseline multilingual tokenizers before you lock a pack.
- **Primary CTA:** Open languages → `/languages`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not production MT certification; not authors’ system
- Sources: arXiv 2607.15209 · authors’ code: none published

## Visual direction
- **Palette:** warm ink + terracotta script accent + parchment mist — wait, avoid cream-terracotta cliché. Use deep espresso ink + teal glyph accent + soft stone mist instead.
  - `--sl-ink: #1c1714`, `--sl-teal: #2f7a6b`, `--sl-stone: #ece8e2`, `--sl-line: #cfc6bc`, `--sl-mark: #a85a2e`
- **Typography:** Newsreader (display) + Figtree (body)
- Full-bleed hero with soft stone mist + faint glyph grid
