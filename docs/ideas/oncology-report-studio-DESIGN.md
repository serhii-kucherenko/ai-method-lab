# Design — Oncology Report Studio

## Brand
**Oncology Report Studio** — soft-sim for multi-LLM collaborative MRI report drafts. Never claim clinical clearance or live PACS.

## Landing brief
- **Headline:** Collaborative report drafts that earn the compare.
- **Support:** Case packs with multi-LLM collaborators — compare against single-model baselines before you lock a report pack.
- **Primary CTA:** Open cases → `/cases`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not clinical decision support; not live PACS; not authors’ system
- Sources: arXiv 2607.14581 · authors’ code: none published

## Visual direction
- **Palette:** slate clinic ink + soft MRI teal + warm bone mist (not purple, not cream-terracotta, not broadsheet)
  - `--or-ink: #15202b`, `--or-teal: #2a7a7b`, `--or-bone: #f0ebe4`, `--or-line: #c8c0b6`, `--or-coral: #c45c4a`
- **Typography:** Fraunces (display) + Source Sans 3 (body)
- Full-bleed hero with soft bone mist + faint report-grid
