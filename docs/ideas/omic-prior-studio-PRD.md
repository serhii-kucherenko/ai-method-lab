# PRD — Omic Prior Studio

## Goal
Soft-sim studio where multi-omics leads compare priors-informed transformers to priors-free baselines for disease and complex-trait prediction.

## Must-have (≥25)
Omic pack CRUD, priors, traits, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Clinical diagnostic claims, live EHR write-back, FDA clearance, OmicFormer brand.
