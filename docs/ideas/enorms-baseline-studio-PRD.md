# PRD — Enorms Baseline Studio

## Goal
Soft-sim studio where EEG analytics leads compare patient-specific E-norms baselines to population-norm baselines for pediatric seizure detection.

## Must-have (≥25)
Baseline pack CRUD, channels, detections, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Clinical diagnostic claims, live EEG control, FDA clearance, paper brand.
