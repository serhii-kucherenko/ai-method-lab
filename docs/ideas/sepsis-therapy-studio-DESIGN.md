# Design — Sepsis Therapy Studio

## Brand
**Sepsis Therapy Studio** — soft-sim for continuous-time HMM antibiotic therapy effectiveness. Never claim clinical diagnostic use, live EHR write-back, or FDA clearance.

## Landing brief
- **Headline:** Judge the regimen before the culture comes back.
- **Support:** Therapy packs for early sepsis antibiotic choices — compare continuous-time HMM effectiveness models against static guideline baselines before you lock a pack.
- **Primary CTA:** Open therapies → `/therapies`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not diagnostic; not live EHR write-back; not FDA cleared; not authors’ system
- Sources: medRxiv 10.64898/2026.07.03.26357092 · authors’ code: none published

## Visual direction
- **Palette:** critical ink + therapy teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--st-ink: #171c24`, `--st-teal: #2a6f6a`, `--st-mist: #eef2f4`, `--st-line: #c3c9ce`, `--st-amber: #c4923a`
- **Typography:** Source Serif 4 (display) + IBM Plex Sans (body)
- Full-bleed hero with soft timeline-state mist
