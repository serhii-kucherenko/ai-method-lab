# Design — Care Query Studio

## Brand
**Care Query Studio** — soft-sim for multilingual point-of-care medical query benchmarking. Never claim clinical diagnostic use, live EHR write-back, or FDA clearance. Not NigBench.

## Landing brief
- **Headline:** Bench the bedside question, not the demo chat.
- **Support:** Query packs for multilingual point-of-care medical questions — compare LLM answers against local clinician baselines before you lock a pack.
- **Primary CTA:** Open queries → `/queries`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not diagnostic; not live EHR write-back; not FDA cleared; not authors’ system; not NigBench
- Sources: medRxiv 10.64898/2026.07.05.26356776 · authors’ code: none published

## Visual direction
- **Palette:** clinic ink + care teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--cq-ink: #1a2228`, `--cq-teal: #2d6f6a`, `--cq-mist: #eef3f2`, `--cq-line: #c5cdcb`, `--cq-amber: #b8893a`
- **Typography:** Literata (display) + Figtree (body)
- Full-bleed hero with soft multilingual-thread mist
