## Buyer
Global-health / clinical LLM eval leads who need to compare multilingual point-of-care medical query LLMs against local clinician baselines before locking a query pack.

## Outcome
A studio to manage query packs, multilingual POC suites, answer runs, and dual compares — then lock when LLM packs beat (or honestly lose to) local clinician baselines while keeping soft-sim honesty.

## Why this paper
NigBench is a multilingual, multimodal point-of-care medical query benchmark comparing LLMs to local general practitioners in Nigeria. Clear software/eval claim — unused after Therapy Prompt. Method Lab product inspired by the pattern, not an authors’ rebrand.

## Business score (pre-climb)
Tier B candidate: clinical LLM eval buyer + query packs; moat is multilingual POC LLM bench vs local clinician baseline.
