# PRD — Feature Sufficiency Studio

## Goal
Ship a comprehensive soft-sim studio where clinical ML ops leads compare partial-observation sufficiency to full-feature baselines using versioned feature packs.

## Must-have (≥25)
Feature pack CRUD, mask editor, cohort cases, sufficiency scorer A/B, compare runs, scoreboard, audit, export, webhook HMAC, org/members, search, bearer auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings, delta view, seed packs, filters, bias controls.

## Non-goals
Clinical advice, live EHR, FDA claims, FSA brand.
