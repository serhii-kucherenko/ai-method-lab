# Design — Reaction Loop Studio

## Brand
**Reaction Loop Studio** — soft-sim for chemist-in-the-loop VLM reaction optimization. Never claim live wet-lab robot control or manufacturing clearance.

## Landing brief
- **Headline:** Keep a chemist in the loop.
- **Support:** Campaign packs with VLM condition agents — compare against open-loop baselines before you lock a pack.
- **Primary CTA:** Open campaigns → `/campaigns`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not live wet-lab control; not manufacturing cleared; not authors’ system
- Sources: ChemRxiv 10.26434/chemrxiv.15006308 · authors’ code: none published

## Visual direction
- **Palette:** reaction ink + flask amber + cool bench mist (not purple, not cream-terracotta, not broadsheet)
  - `--rl-ink: #1a1714`, `--rl-amber: #c48a2a`, `--rl-mist: #f0ece6`, `--rl-line: #c9c0b6`, `--rl-teal: #3a6f68`
- **Typography:** Fraunces (display) + Karla (body)
- Full-bleed hero with soft bench mist + faint loop-grid
