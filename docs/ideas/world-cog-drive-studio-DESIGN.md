# Design — World Cog Drive Studio

## Brand
**World Cog Drive Studio** — soft-sim for dual-level world-cognitive VLA driving. Never claim certified AV or live vehicle control.

## Landing brief
- **Headline:** Forecast the world. Then act.
- **Support:** Route packs with dual-level world-cognitive policies — compare against single-level VLA baselines before you lock a pack.
- **Primary CTA:** Open routes → `/routes`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not certified AV; not live vehicle control; not authors’ system
- Sources: arXiv 2607.08375 · authors’ code: none published

## Visual direction
- **Palette:** asphalt ink + signal amber + cool fog (not purple, not cream-terracotta, not broadsheet)
  - `--wc-ink: #12161c`, `--wc-amber: #d89a2a`, `--wc-fog: #e8ecf0`, `--wc-line: #b8c0c8`, `--wc-teal: #2f6f78`
- **Typography:** Archivo (display) + Work Sans (body)
- Full-bleed hero with soft fog mist + faint route-grid
