# PRD — Coload Order Studio

## Goal
Soft-sim studio where nanomedicine formulation leads compare ordered chemo-photothermal co-load sequences to simultaneous-load baselines.

## Must-have (≥25)
Carrier pack CRUD, loads, assays, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validated GMP nanomedicine claims, live patient dosing, clinical oncology clearance, paper brand.
