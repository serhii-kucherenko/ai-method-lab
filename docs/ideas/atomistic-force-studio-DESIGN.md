# Design — Atomistic Force Studio

## Brand
**Atomistic Force Studio** — soft-sim for foundation-model atomistic forces. Never claim production DFT-validated manufacturing sims or live HPC write-back.

## Landing brief
- **Headline:** Atomistic forces that earn a foundation model.
- **Support:** Sim packs with foundation-model atomistics — compare against classical force-field baselines before you lock a pack.
- **Primary CTA:** Open sims → `/sims`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not DFT-validated manufacturing; not live HPC; not authors’ system
- Sources: ChemRxiv 10.26434/chemrxiv-2025-f1hgn · authors’ code: none published

## Visual direction
- **Palette:** lattice ink + force teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--af-ink: #121820`, `--af-teal: #2f7f8a`, `--af-mist: #eef2f4`, `--af-line: #c2c9ce`, `--af-amber: #c4923a`
- **Typography:** Sora (display) + IBM Plex Sans (body)
- Full-bleed hero with soft lattice mist + faint force-grid
