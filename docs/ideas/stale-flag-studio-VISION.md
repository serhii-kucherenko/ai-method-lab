# Stale Flag Studio — Vision

Feature flags quietly rot into permanent conditionals until a release freeze becomes a scavenger hunt. Stale Flag Studio soft-sims a **flag inventory debt queue** - past expiry, stuck-true, unused - with owners and blast radius versus an ignore-stale baseline so platform leads freeze with a cleanup pack, not a vendor console dump.

**Refuse to become:** LaunchDarkly UI clone, Change Freeze (OT holds), Delegation Expiry (agent grants), or desk jobs/lifecycle shell.
