# PRD — Encoded Library Studio

## Goal
Soft-sim studio where DELT chemistry leads compare iterative DNA-encoded library construct-and-screen cycles to single-pass library screens.

## Must-have (≥25)
Library pack CRUD, cycles, hits, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validated IND/NDA claims, live screening robotics, clinical candidate nomination, paper brand.
