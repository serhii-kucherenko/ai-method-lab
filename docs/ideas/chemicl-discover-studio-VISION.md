# Vision — Chemicl Discover Studio

## Problem
Text-only in-context learning misses multimodal chemistry signals. Teams lack a soft-sim bench that compares ChemICL-style multimodal ICL to text-only baselines before locking a discover pack.

## Buyer
Chemistry discovery / ML-for-chem eng leads.

## Promise
Version discover packs, configure exemplars and modalities, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not a reaction-loop or synth-confidence desk. Domain nouns: discovers, exemplars, modalities, runs, compares.
