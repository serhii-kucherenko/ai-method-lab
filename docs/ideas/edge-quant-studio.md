# Edge Quant Studio

**State:** complete  
**Slug:** `edge-quant-studio`  
**Paper:** https://arxiv.org/abs/2607.14618v1  
**Authors’ code:** none  

## Buyer
ML platform and edge infrastructure engineers who must run large language models on CPUs without burning latency or memory on a one-size-fits-all bit width.

## Outcome
A studio to plan channel-aware quantization, compare against uniform baselines, validate compile/runtime plans, and show cost/latency honesty before a model ships to edge CPUs.

## Why this paper
PolyQ claims end-to-end codesign of per-channel bit widths with a CPU-oriented compile path. Clear infra/cost software claim — preferred over more clinical carepath clones under biz-rubric-v1. No public authors’ code in the digest — Method Lab product inspired by the pattern, not a rebrand of PolyQ.

## Business score (pre-climb)
Tier B candidate: buyer + money hook via toolchain seats; moat is channel-aware plan vs uniform quant dashboards.
