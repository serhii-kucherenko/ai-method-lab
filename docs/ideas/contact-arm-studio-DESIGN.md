# Design — Contact Arm Studio

## Brand
**Contact Arm Studio** — robotics soft-sim for contact-centric whole-arm plans. Never brand as TACTIC.

## Landing brief
- **Headline:** Plan contact where the arm actually touches.
- **Support:** Manipulator packs with tactile+vision cues — compare contact-centric control against vision-only baselines before you lock a pack.
- **Primary CTA:** Open manipulators → `/manipulators`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not live robot control; not safety certification; not authors’ system
- Sources: arXiv 2607.09218 · authors’ code: none published

## Visual direction
- **Palette:** graphite ink + signal orange contact accent + cool steel mist (not purple, not cream-terracotta, not broadsheet)
  - `--ca-ink: #1b1f24`, `--ca-orange: #d9772f`, `--ca-steel: #5b7c8a`, `--ca-mist: #e8eef1`, `--ca-panel: #ffffff`
- **Typography:** Space Grotesk (display) + Source Sans 3 (body) — not Inter/Roboto/Arial
- **Atmosphere:** soft industrial mist + faint contact-point grid, full-bleed hero

## Layout rules
One composition first viewport; brand-first; cards only for interactive work surfaces.

## Motion
1. Hero mist fade-in  
2. CTA underline draw  
3. Contact-plan row highlight
