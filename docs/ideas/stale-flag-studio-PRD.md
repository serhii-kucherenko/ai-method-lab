# Stale Flag Studio — PRD

**Problem:** Platform and release leads enter freeze windows without a clear queue of flags that are past expiry, permanently true, or unused - with owners and blast radius.  
**Solution:** Soft-sim studio that imports flag inventory, classifies debt, and compares debt-aware path (A) vs ignore-stale path (B).  
**Success:** ≥25 features; ≥11 pages including `/`, `/pricing`, `/demo`, `/onboarding`, `/flows`; dual-impl ≥30 goldens; live app smoke.  
**Out of scope:** Replacing live flag vendors; OT change holds; agent tool grants; clinical/device/wet-lab.
