# Vision — Fluoride Label Studio

## Problem
Multistep prosthetic-group fluorine-18 labeling is slow and brittle. Teams lack a soft-sim bench that compares fast isotopic exchange designs to prosthetic baselines before locking a label pack.

## Buyer
Radiopharma / PET tracer chemistry analytics eng leads.

## Promise
Version label packs, configure precursors and exchange runs, run dual compares, lock when deltas and honesty are understood — method-lab soft-sim only.

## Differentiation
Not an encoded-library or probe-domain desk. Domain nouns: packs, precursors, exchanges, tracers, assays, runs, compares.
