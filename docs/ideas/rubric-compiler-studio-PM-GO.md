# PM GO — Rubric Compiler Studio

**Role:** Product manager  
**Date:** 2026-07-26  
**Decision:** `decision: go`

## Why go

Software-solvable business idea under **biz-rubric-v2**. Eval / platform leads already buy LLM judges and benches; flaky holistic scores are a weekly pain. Method is the product (compile → evidence → calibrate → escalate) — not a clinical or wet-lab skin.

## Selling points

1. Lock rubrics as executable measurement specs (not drifting prompt prose)
2. Evidence-anchored criterion scores buyers can audit
3. Scale calibration against human raters
4. Reliability / validity diagnostics (not agreement theater)
5. Selective trust — escalate when the judge is unsure
6. Dual compare: compiled rubric path vs holistic single-score baseline

## Buyer / money

- **Buyer:** Platform / eval engineering leads; L&D and QA scoring owners
- **Money:** Team seats + per-score-run / private rubric packs
- **PMF signal:** Rising LLM-as-judge spend; RULERS / Autorubric / PReMISE literature cluster

## Non-goals

- Medical / clinical / device / wet-lab judge products
- Recruiting-only app (hiring may be a later demo skin)
- Desk shell noun-swap (`/jobs` `/lifecycle` `/scenario` `/batch` `/goldens`)
- Claiming live production judge API write-back or certified psychometrics
