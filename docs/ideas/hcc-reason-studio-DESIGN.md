# Design — HCC Reason Studio

## Brand
**HCC Reason Studio** — soft-sim for clinical-reasoning HCC risk pathways. Never claim CDS clearance or live EHR.

## Landing brief
- **Headline:** Reasoning pathways that earn the compare.
- **Support:** Pathway packs with clinical reasoners — compare against non-reasoning baselines before you lock a pack.
- **Primary CTA:** Open pathways → `/pathways`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not clinical decision support; not live EHR; not authors’ system
- Sources: arXiv 2607.08602 · authors’ code: none published

## Visual direction
- **Palette:** hepatic wine + soft gold + linen mist (not purple, not cream-terracotta, not broadsheet)
  - `--hr-ink: #2a1518`, `--hr-wine: #8b3a42`, `--hr-gold: #c4a35a`, `--hr-mist: #f3eee8`, `--hr-line: #d2c6ba`
- **Typography:** Libre Baskerville (display) + Nunito Sans (body)
- Full-bleed hero with soft linen mist + faint pathway-grid
