# PRD — Track Map Studio

Soft-sim studio where surgical robotics leads compare online deformable SLAM to offline kinematics-prior baselines.

Track pack CRUD, poses, reconstructions, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Live robot control, clinical diagnostic claims, FDA clearance, Track2Map brand.
