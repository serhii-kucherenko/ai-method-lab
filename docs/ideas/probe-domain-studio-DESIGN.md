# Design — Probe Domain Studio

## Brand
**Probe Domain Studio** — soft-sim for cooperative multi-domain DNA probe design. Never claim wet-lab validated diagnostics, live IVD clearance, or whole-blood device deployment.

## Landing brief
- **Headline:** Split the probe. Sharpen the match.
- **Support:** Probe packs for nucleic acid detection — compare cooperative multi-domain designs against single-domain melting baselines before you lock a pack.
- **Primary CTA:** Open packs → `/packs`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not wet-lab validated; not IVD cleared; not a whole-blood device; not authors’ system
- Sources: ChemRxiv 10.26434/chemrxiv.15006161 · authors’ code: none published

## Visual direction
- **Palette:** assay ink + probe teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--pd-ink: #14191f`, `--pd-teal: #2a6a72`, `--pd-mist: #eef3f5`, `--pd-line: #c2c8cd`, `--pd-amber: #b8873a`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft dual-strand probe mist
