# Design — Quantum Kernel Studio

## Brand
**Quantum Kernel Studio** — chem-informatics soft-sim. Never brand as Q²SAR; never claim live quantum hardware.

## Landing brief
- **Headline:** Kernel plans that beat classical QSAR baselines.
- **Support:** Molecule packs with quantum multiple-kernel configs — compare against classical kernels before you lock a pack.
- **Primary CTA:** Open molecules → `/molecules`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not wet-lab; not live quantum hardware; not authors’ system
- Sources: arXiv 2607.11701 · authors’ code: none published

## Visual direction
- **Palette:** deep indigo ink + lime kernel accent + cool chalk mist (not purple-on-white gradient cliché as primary theme, not cream-terracotta, not broadsheet)
  - `--qk-ink: #12182a`, `--qk-lime: #8fb83a`, `--qk-chalk: #eef1f4`, `--qk-line: #c5ced8`, `--qk-signal: #3d7ea6`
- **Typography:** Outfit (display) + Source Sans 3 (body)
- **Atmosphere:** soft chalk mist + faint kernel-grid pattern, full-bleed hero
