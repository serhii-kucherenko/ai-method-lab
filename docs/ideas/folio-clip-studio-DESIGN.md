# Design — Folio Clip Studio

## Brand
**Folio Clip Studio** — soft-sim for multimodal plant-stress wearables. Never claim field-validated farm deployments or live greenhouse control.

## Landing brief
- **Headline:** Plant stress, clipped in multimodal.
- **Support:** Clip packs with multimodal wearable sensing — compare against single-sensor baselines before you lock a pack.
- **Primary CTA:** Open clips → `/clips`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not field-validated; not live greenhouse write-back; not authors’ system
- Sources: ChemRxiv 10.26434/chemrxiv.15005167 · authors’ code: none published

## Visual direction
- **Palette:** leaf ink + sap green + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--fc-ink: #14201a`, `--fc-sap: #3f8f5a`, `--fc-mist: #eef3ef`, `--fc-line: #c5d0c8`, `--fc-amber: #c49a3a`
- **Typography:** Fraunces (display) + DM Sans (body)
- Full-bleed hero with soft leaf mist + faint clip-grid
