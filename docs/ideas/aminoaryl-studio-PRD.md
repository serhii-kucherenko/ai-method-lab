# PRD — Aminoaryl Studio

## Goal
Soft-sim studio where medchem analytics leads compare photocatalytic 1,3-aminoarylation to copper-catalyzed baselines for diarylpropylamine route planning.

## Must-have (≥25)
Route pack CRUD, catalysts, assays, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validation, scale-up manufacturing control, regulatory filing authority, paper brand.
