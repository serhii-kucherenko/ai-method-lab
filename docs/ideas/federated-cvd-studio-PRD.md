# PRD — Federated CVD Studio

## Goal
Soft-sim studio where cardiology ML leads compare federated CVD risk models to centralized baselines.

## Must-have (≥25)
Cohort pack CRUD, feature schemas, federation configs, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
FDA clearance, live EHR, paper brand.
