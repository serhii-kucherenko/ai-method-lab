# Design — Pneumonia Implement Studio

## Brand
**Pneumonia Implement Studio** — soft-sim for CFIR co-designed childhood pneumonia care vs status-quo pathways. Never claim live clinical triage, EMR write-back, or government program authority.

## Landing brief
- **Headline:** Co-design the pathway. Prove the fidelity.
- **Support:** District packs for childhood pneumonia implementation — compare CFIR co-design against status-quo pathways before you lock a pack.
- **Primary CTA:** Open packs → `/packs`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not live triage; not EMR write-back; not government authority; not authors’ study brand
- Sources: medRxiv 10.64898/2026.07.16.26358238 · authors’ code: none published

## Visual direction
- **Palette:** clinic ink + care teal + soft chalk (not purple, not cream-terracotta, not broadsheet)
  - `--pi-ink: #14181c`, `--pi-teal: #1a6460`, `--pi-chalk: #eef2f1`, `--pi-line: #c5cbc9`, `--pi-amber: #a87a2e`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft chalk-field mist
