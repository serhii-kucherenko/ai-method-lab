# Design — Therapy Prompt Studio

## Brand
**Therapy Prompt Studio** — soft-sim for comparing structured therapy-safety gates to prompt-only LLM safety. Never claim clinical therapy, crisis hotline replacement, live patient chat write-back, or FDA clearance.

## Landing brief
- **Headline:** Prompt-only therapy safety is not enough.
- **Support:** Prompt packs for high-risk psychiatric scenarios — compare structured safety gates against prompt-only baselines before you lock a pack.
- **Primary CTA:** Open prompts → `/prompts`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not clinical therapy; not a crisis line; not live patient chat; not FDA cleared; not authors’ system
- Sources: medRxiv 10.64898/2026.07.16.26358261 · authors’ code: none published

## Visual direction
- **Palette:** clinic ink + calm teal + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--tp-ink: #1a2228`, `--tp-teal: #2f6f6a`, `--tp-mist: #eef3f2`, `--tp-line: #c5cdcb`, `--tp-amber: #b8893a`
- **Typography:** Source Serif 4 (display) + IBM Plex Sans (body)
- Full-bleed hero with soft safety-gate mist
