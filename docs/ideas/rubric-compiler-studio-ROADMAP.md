# Roadmap — Rubric Compiler Studio

1. **Smoke** — Next.js + claim + honesty fence + landing sells buyer outcome  
2. **Domain** — Dual score: compiled evidence-anchored rubric (A) vs holistic baseline (B); ≥30 goldens  
3. **Studio UI** — `/rubrics` `/criteria` `/runs` `/calibration` `/escalations` `/compare` `/scoreboard`  
4. **Commercial** — `/pricing` `/demo` `/onboarding` `/flows` (≥5 journeys) + platform must-haves  
5. **Sustain** — ≥25 features, ≥11 pages, README, tutor guide, try.html, live app-up, finish email  

## ARS module phases (from MODULE-MAP — single product)

Do **not** open sibling scoring studios. Fold papers into this climb:

| Phase unlock | Module | Paper seed |
|--------------|--------|------------|
| After domain | **Recipe templates** — criterion types, ensembles, few-shot calibration packs | Autorubric |
| After lock UX | **Measurement Spec / Policy Lock** — who locked what, against which suite, rollback | PReMISE |
| With escalations | **Selective Trust** — cheap→strong + human queue SLAs | Trust or Escalate |
| After first runs | **Judge Health** — reliability diagnostics (plain-language, not clinical IRT cosplay) | IRT diagnosis |
| CI / suites | **Bias Hardening** — rubric order, score-ID, reference-answer gates | Scoring bias |
| With calibration | **Validity Suite** — gold anchors; warn when agreement ≠ validity | Reliability without Validity |
| Compare expand | **Mode Compare** — rubric vs preference (not only A vs holistic B) | JudgmentBench |
| Scoreboard deepen | **Criterion Meta-Eval** — per-criterion judge accuracy | RubricEval |
| Landing / docs | **Structured-criteria narrative** — holistic→rubric education only | Holistic→structured survey |
