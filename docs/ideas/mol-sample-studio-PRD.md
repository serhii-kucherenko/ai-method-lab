# PRD — Molecule Sample Studio

## Goal
Soft-sim studio where medchem leads compare sample-efficient generative optimization to naive generative baselines.

## Must-have (≥25)
Campaign pack CRUD, property targets, optimizer configs, dual scorer A/B, compare, scoreboard, audit, export, webhook, org/members, search, auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings.

## Non-goals
Wet-lab validation, live ELN, paper brand.
