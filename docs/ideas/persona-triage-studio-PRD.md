# PRD — Persona Triage Studio

## Goal
Ship a comprehensive soft-sim studio where clinical AI eval leads compare style-aware triage scoring to idealized-patient baselines using versioned persona packs.

## Users
- Eval lead (primary)
- Org admin (settings)

## Must-have features (≥25)
Persona CRUD, pack versions, conversation cases, style axes, urgency labels, dual scorer A/B, compare runs, scoreboard, audit log, export, webhook HMAC, org/members, search, bearer auth, pagination, rate limit, goldens ≥30, try.html, pricing, demo, onboarding, flows (≥5), honesty, landing, settings, disparity delta view, persona seed packs, case filters, style bias controls.

## Non-goals
Clinical advice, live chatbot hosting, FDA claims, authors’ system rebrand.
