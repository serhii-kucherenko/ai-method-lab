# Design — Coload Order Studio

## Brand
**Coload Order Studio** — soft-sim for ordered chemo-photothermal co-loading into hollow mesoporous carriers. Never claim wet-lab validated GMP nanomedicine manufacture, live patient dosing, or clinical oncology clearance.

## Landing brief
- **Headline:** Order the load. Fill the pore.
- **Support:** Carrier packs for chemo-photothermal formulation — compare ordered co-load sequences against simultaneous-load baselines before you lock a pack.
- **Primary CTA:** Open packs → `/packs`
- **Secondary:** See demo → `/demo`
- Honesty: soft-sim only; not GMP nanomedicine; not live dosing; not clinical oncology clearance; not authors’ system
- Sources: Nanomaterials 10.3390/nano16130805 · authors’ code: none published

## Visual direction
- **Palette:** lab ink + pore slate + cool mist (not purple, not cream-terracotta, not broadsheet)
  - `--co-ink: #12161b`, `--co-slate: #3a5566`, `--co-mist: #eef2f4`, `--co-line: #c4c9ce`, `--co-amber: #b4833a`
- **Typography:** Fraunces (display) + Manrope (body)
- Full-bleed hero with soft mesopore mist
