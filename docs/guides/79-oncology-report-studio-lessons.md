# Oncology Report Studio — what we learned

## Copy next time

- Domain IA must match the paper claim: **cases → schemas → collaborators → drafts**, not jobs/lifecycle/scenario desks.
- Dual scorers need mirrored `scoreA` / `scoreB` plus ≥30 fixtures regenerated from one generator.
- Landing brand (Fraunces + Source Sans 3, slate clinic ink / MRI teal / bone mist / coral) must survive removing the nav.
- Ship `/pricing`, `/demo`, `/onboarding`, `/flows` (≥5 named journeys) before calling the product complete.
- Honesty: soft-sim only; not clinical decision support; not live PACS; not the authors’ system.

## Refuse next time

- Noun-swapping a kinetics or lexicon desk into an oncology shell without rewriting nouns, scorers, and goldens.
- Claiming authors' code when none is published.
- Sending finish email from the product agent when `product_complete_pending` is owned by the parent.
