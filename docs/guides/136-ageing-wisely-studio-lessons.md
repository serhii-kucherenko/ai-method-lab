# 136 — Ageing Wisely Studio lessons

## What we shipped

A comprehensive soft-sim studio for **therapist-supported internet CBT** vs **waitlist / self-guided baselines** aimed at geriatric digital mental-health / care-delivery analytics leads.

## Category practices that landed

| Practice | Where |
|----------|--------|
| Versioned care packs | `/packs` |
| Cohort + module path workspace | `/cohorts`, `/modules` |
| Session soft-sim runs | `/sessions` |

| Goldens ≥30 (`aw-001`…`aw-030`) | `src/goldens.ts` + fixtures |

## What not to claim

- Clinical diagnosis
- Live therapist replacement
- Regulated digital therapeutic clearance
- Authors’ Ageing Wisely Online program branding

## Anti-clone note

Domain nouns are packs, cohorts, modules, sessions — not jobs / lifecycle / scenario shells, and not coload / nanomedicine desks.
