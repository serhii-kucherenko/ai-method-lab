# Shared Risk Studio — what we learned

## Copy this

- Domain nouns that match the buyer job: **cohorts**, **modalities**, **queries**, **runs** — not jobs/lifecycle/scenario shells.
- Dual scorers named for the paper pattern: shared multi-disease representation vs disease-specific baseline.
- Brand-first landing with Literata + Source Sans 3 and biobank navy / soft mint / cool paper / coral — honesty fence in the first commercial fold.
- ≥5 named flows with actor / job / success / emptyError before claiming “comprehensive.”

## Refuse this

- Claiming CDS clearance or live EHR write-back.
- Noun-swapping a desk template onto shared risk.
- Shipping without `/pricing`, `/demo`, `/onboarding`, `/flows`, and live app-up smoke.
- Branding as RisQ or claiming the authors’ system.
