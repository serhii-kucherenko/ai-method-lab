# Saffron Detect Studio — what we learned

Tutor guide for Method Lab product `saffron-detect-studio`.

## Category practices shipped

Eval / authenticity bench:

- Goldens (≥30 dual-impl `sd-001…sd-030`)
- Dual compare (CNN adulteration detection vs visual inspection baseline)
- Scoreboard + versioned detect packs
- Honesty fence (soft-sim; not customs / lab / supply-chain write-back)
- Platform must-haves: bearer auth, org/members, audit, export, HMAC webhook, rate limit, search, pagination

## What not to claim

Never claim field-validated customs authority, live supply-chain write-back, or certified lab accreditation. Not an authors’ rebrand of the Research Square CNN study.

## Anti-clone

Domain IA only: detects, images, models, runs, compares. No `/jobs` `/lifecycle` `/scenario` isomorphic desk shells.

## Flows (≥5)

1. Create detect pack  
2. Register stigma images  
3. Configure CNN models  
4. Run A/B compare  
5. Export + webhook  

## Design tokens

Libre Baskerville + Source Sans 3; stigma ink / saffron amber / cool mist / teal — not purple, not cream-terracotta broadsheet.
