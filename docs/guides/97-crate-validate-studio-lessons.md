# 97 — Crate Validate Studio lessons

## What shipped
A comprehensive soft-sim studio where research-data / FAIR tooling leads version **crate packs**, configure **structural + semantic validation rules** and **Frictionless-style checks**, run **validation soft-sim runs**, and compare **ARC structural+semantic validation (A)** against a **metadata-only baseline (B)** before locking.

## Category practices
- Eval / FAIR soft-sim: dual A/B, goldens (cv-001…cv-030), scoreboard, honesty fence
- Platform: bearer auth, org/members, audit, export JSON/CSV, webhook HMAC, rate limit, pagination, search

## Domain IA (anti-clone)
Routes use crates / rules / checks / runs / compares — not jobs / lifecycle / scenario desk shells.

## Honesty
Soft-sim only. Never claim institutional repository write-back or live ARC farm control. Not an authors’ rebrand of BioHackrXiv zah28.

## Brand
Outfit + Source Sans 3; crate ink / validate teal / cool mist.

## Takeaways
1. Domain nouns must match the buyer story — “crate pack” beats a renamed desk.
2. Dual scorers need ≥30 goldens so lock decisions are regression-tested.
3. Commercial surfaces (`/pricing`, `/demo`, `/onboarding`, `/flows`) carry the product past a calculator costume.
