# Lessons — Edge Quant Studio

## What worked

- **Domain-first IA** — `/packs` `/channels` `/targets` `/runtime` `/budgets` `/compare` reads as a quantization / edge-CPU planning workflow, not a noun-swapped desk or Legacy Infer `/devices` shell.
- **Dual score with an honest gap** — channel-aware plan quality (A) vs naive uniform bit-width (B) makes the buyer claim falsifiable in goldens and on `/compare`.
- **Landing sells the edge outcome** — plan bits where the CPU can keep them, before shipping uniform W3 and praying about memory.

## What to avoid next time

- Branding as PolyQ or claiming measured silicon / authors’ compiler; keep the honesty fence early and visible.
- Copying Model Compile `/models` `/compile` `/artifacts` or Prompt Cache `/prompts` shells — this product needs packs, channels, runtime, and budgets.
- Skipping live `next build` + `next start` smoke; API/unit green alone is not sustain.

## Patterns to reuse

- Dual-impl scoring (`quant.ts` / `quantB.ts`) with ~30 fixtures.
- In-memory store + bearer/webhook/export for comprehensive API bar.
- Tutor guide + `try.html` before finish email.
