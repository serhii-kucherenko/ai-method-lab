# Folio Clip Studio — what we learned

## Copy this
- Domain nouns: clips, sensors, stress, runs, compares — not jobs/lifecycle/scenario desk shells
- Dual scorers named for the paper pattern: multimodal wearable stress vs single-sensor baseline
- Brand-first landing (Fraunces + DM Sans; leaf ink / sap green / cool mist)
- ≥5 named flows on `/flows` with actor, job, steps, success, empty/error
- Soft-sim honesty fence: not field-validated farm deployments, not live greenhouse write-back, not authors’ system

## Refuse this
- Overclaiming field farm validation or live greenhouse control
- Isomorphic desk clones with noun-swapped pages
- Shipping without `/pricing`, `/demo`, `/onboarding`, or multi-flow index
- Same-tick paper pick → smoke scaffold without PM/design pack

## Scoring notes
Maturity passed when 13 pages, 35 features, 30 dual-impl goldens (fc-001…fc-030), and app-up were green. Category practices: goldens, dual compare, scoreboard, versioned clip packs, audit/export/webhook/org.
