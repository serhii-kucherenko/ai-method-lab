# Omic Prior Studio — lessons

## What we built
A soft-sim studio for precision-medicine / multi-omics analytics leads to compare statistical-priors-informed transformers against priors-free omics baselines before locking an omic pack.

## Category practices shipped
- Eval / multi-omics bench: goldens (≥30), dual A/B scorers, scoreboard, versioned packs
- Platform: bearer auth, org/members, audit, export JSON/CSV, HMAC webhook, rate limit, pagination, search

## Domain IA (anti-clone)
Omics, priors, traits, runs, compares — not `/jobs` `/lifecycle` `/scenario` desk shells. Not OmicFormer brand.

## Honesty fence
Soft-sim only — not clinical diagnostic use, not live EHR write-back, not FDA cleared, not OmicFormer, not the authors’ system.

## Dual scorers
- A: `priors_informed_transformer`
- B: `priors_free_omics_baseline`

## What we deferred
Live EHR write-back, clinical diagnostic claims, FDA pathway packaging — intentionally out of scope for method-lab soft-sim.
