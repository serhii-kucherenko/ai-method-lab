# HCC Reason Studio — what we learned

## Copy next time

- Domain IA must match the paper claim: **pathways → schemas → reasoners → runs**, not jobs/lifecycle/scenario desks.
- Dual scorers need mirrored `scoreA` / `scoreB` plus ≥30 fixtures regenerated from one generator.
- Landing brand (Libre Baskerville + Nunito Sans, hepatic wine / soft gold / linen mist) must survive removing the nav.
- Ship `/pricing`, `/demo`, `/onboarding`, `/flows` (≥5 named journeys) before calling the product complete.
- Honesty: soft-sim only; not CDS; not live EHR; not the authors’ system.

## Refuse next time

- Noun-swapping a CVD or oncology desk into an HCC shell without rewriting nouns, scorers, and goldens.
- Claiming authors' code when none is published.
- Sending finish email from the product agent when `product_complete_pending` is owned by the parent.
