# Federated CVD Studio — what we learned

## Copy next time

- Domain IA must match the paper claim: **cohorts → features → federation → runs**, not jobs/lifecycle/scenario desks.
- Dual scorers need mirrored `scoreA` / `scoreB` plus ≥30 fixtures regenerated from one generator.
- Landing brand (Literata + DM Sans, cardio navy / pulse rose / cool mist / teal) must survive removing the nav.
- Ship `/pricing`, `/demo`, `/onboarding`, `/flows` (≥5 named journeys) before calling the product complete.
- Honesty: soft-sim only; not FDA cleared; not live EHR; not the authors’ system.

## Refuse next time

- Noun-swapping an oncology or kinetics desk into a CVD shell without rewriting nouns, scorers, and goldens.
- Claiming authors' code when none is published.
- Sending finish email from the product agent when `product_complete_pending` is owned by the parent.
