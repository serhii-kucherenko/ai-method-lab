# Attest Proof Studio — lessons

Guide **64** for the Method Lab climb of **Attest Proof Studio** (EG-VAR paper input).

## What we built

A trust/eval studio where teams register empirical claims, attach tool attestations, walk soft-sim kernel proof chains, keep an evidence ledger, and compare tool-attested proof quality against a fluent-only baseline.

## Lessons

1. **Trust IA beats desk clones** — claims → attestations → proofs → kernel → ledger → compare is the buyer story; `/jobs` `/lifecycle` shells fail the comprehensive bar. Required commercial surfaces: `/pricing` (tiers), `/demo` (guided steps), `/onboarding` (checklist progress).
2. **Cousin ≠ clone** — Reason Frame is debate/game checks; Agent Safety is fleet monitors. Do not copy `/rules` `/debates` or monitor desks.
3. **Honesty early** — soft-sim proof chains, not EG-VAR rebrand, not production Lean 4. Landing + `/honesty` must say it.
4. **Dual score needs a real baseline** — fluent-only that rewards confidence without tools is the falsifier for “looks verified.”
5. **Goldens lock the claim** — ~30 dual fixtures keep attested vs fluent math honest across two scoring modules.
6. **Live app gate** — `next build` + app-up smoke on `/` with the display name is non-negotiable before sustain.
