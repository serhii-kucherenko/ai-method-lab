# Crystal Bind Studio — lessons

Guide **63** for the Method Lab climb of **Crystal Bind Studio** (MatBind paper input).

## What we built

A materials-facing studio where teams register crystal packs, keep four descriptor lanes (structure / diffraction / DOS / language), project a shared bind space, and compare multimodal retrieve quality against a single-modality baseline.

## Lessons

1. **Industrial IA beats desk clones** — packs → lanes → bind → retrieve is a materials story; `/jobs` `/lifecycle` shells fail the comprehensive bar.
2. **Honesty early** — soft-sim embeddings, not MatBind rebrand, not wet-lab spectra. Landing + `/honesty` must say it.
3. **Dual score needs a real baseline** — single-modality collapse (ignore cross-modal) is the falsifier; uniform bit-width / catalog-only patterns from other products do not transfer.
4. **Cousin ≠ clone** — Optical Stack is the industrial design cousin; do not copy briefs/stacks or Edge Quant channels IA.
5. **Goldens lock the claim** — ~30 dual fixtures keep multimodal vs single math honest across two scoring modules.
6. **Live app gate** — `next build` + app-up smoke on `/` with the display name is non-negotiable before sustain.
