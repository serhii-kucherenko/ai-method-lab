# Retro Route Studio — lessons

## What shipped
A chem / synthesis-planning soft-sim studio with versioned route packs, structured search memory, intermediate properties, and dual A/B scoring (structured-memory agentic vs naive local greedy). Commercial surfaces: `/pricing`, `/demo`, `/onboarding`, `/flows` (≥5 named journeys), `/honesty`.

## Category practices
Eval / chem-planning bench: goldens (≥30), dual compare, scoreboard, versioned packs, audit, export, org/members, webhook, search, honesty fence, offline `try.html`.

## What worked
- Domain IA (packs/routes/memory/intermediates) avoided desk-clone and Crystal Bind noun-swap.
- Dual-impl twin (`route.ts` / `routeB.ts`) kept goldens honest without weakening tests.
- Money hook stayed seats + private route packs with method-lab packaging honesty.

## Deferrals
- No live LLM agent loop (soft-sim score only).
- No wet-lab / robotic execution integration (explicit non-goal).
- No regulatory synthesis certification claims.

## Anti-patterns avoided
Branding as RetroAgent; isomorphic `/jobs`/`/lifecycle`/`/scenario` shells; claiming wet-lab execution.
