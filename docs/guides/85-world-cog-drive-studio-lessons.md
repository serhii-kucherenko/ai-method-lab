# World Cog Drive Studio — lessons

## What we shipped
A soft-sim studio for autonomy leads: route packs, world forecasts, action policies, dual A/B (world-cognitive vs single-level VLA), scoreboard, and platform must-haves.

## Keep
- Domain IA (`/routes` `/worlds` `/policies`) — not desk/jobs/lifecycle shells
- Honesty fence: soft-sim only; not certified AV; not live vehicle control; not authors’ system
- Dual goldens that lock both scorers

## Avoid
- Noun-swapping Drive Horizon packs/scenes/generators
- Claiming certified AV or live fleet control
- Purple / cream-terracotta / broadsheet default looks

## Buyer story
Forecast the world, then act — lock a pack only when dual-level world-cognitive scores beat single-level baselines.
